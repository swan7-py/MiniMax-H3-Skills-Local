# Handdrawn Live-Action Fusion Video Generator（本地版 · 逐步确认式）

> 本文件由原始 skill `handdrawn-live-video-generator` 改造为「本地版 · 逐步确认式」。
> **本地化改造总则 v2（纯提示词 · 逐步确认 · 交付物门）**
>
> **⏹ 门控硬规则（真停顿 · 已生效）**：本 skill 中每个 `⏸ 确认门` 与 `⏸ 交付物门` 均为**硬性停止点**，不是建议。固定执行顺序：① 仅输出当前步骤交付物（提示词 / 文本计划 / 分镜脚本等）；② **立即调用 AskUserQuestion 工具**，给三选项「✅ 确认，继续下一步」「✏️ 修改当前步」「⏸ 暂停 / 停止或换方向」；③ **等待用户回复**，本回复内**绝不可预生成任何后续步骤**（即使你觉得能一次写完）。任一 `⏸` 门不得跳过 / 合并，也不得仅用一句"请确认"文字代替——必须用 AskUserQuestion 真正阻塞。
> 1. **本 skill 无生图步骤**（纯文生视频）；如未来需静帧，只给文生图提示词、用户自行生图并返回地址，不硬编码任何 ComfyUI 路径。
> 2. **每一步都确认 + 交付物门（核心规则）**：每个步骤产出后我都会暂停，等你「确认 / 修改」。视频步骤生成后，等你**返回视频地址（可选）**或确认后再继续。
> 3. **视频提示词调用 `h3-prompt-writing` skill**：视频提示词调用用户级 `h3-prompt-writing` skill（纯文本、无需 API）来写；本 skill 为纯文生视频（T2VA），无参考图，按其 T2VA 结构输出完整 H3 视频提示词，并附设置建议，由你在本地 H3 节点自行执行。
> 4. **语音 / 音乐先询问（已升级为「音频模式门」）**：进入流程第一步（方向/简报锁定）时，必须先用 AskUserQuestion 问你**音频方案**，二选一：
>    - **A) 统一 H3 音频**：旁白 + 对白 + BGM 全部由 H3 原生音频驱动生成（最省事，音色/配乐与画面同步，无需外部文件）。
>    - **B) 分离生成**：旁白/对白只给提示词（你用任意 TTS 工具，推荐用「参考/音色克隆」模式保证跨镜头一致；不绑定 MOSS-TTS）、BGM 用 ACE-Step 1.5 本地生成（调用 `ace-step-1.5-prompt-writer` skill）、对白分别生成，后期合成。
>    - 记录你的选择，后续「视频提示词步骤」与「音频步骤」依此分支执行。
> 5. **旁白/对白一致性（分离模式必做）**：若选 B 且含旁白/对白，提醒你把【音色参考文件】（.wav/.mp3，代表目标音色）放到**当前项目文件夹（你运行本 skill 的工作目录）**，并在调用 TTS 时使用「参考模式 / 音色克隆」，确保多镜头音色统一；若你未提供该文件，先暂停请其提供，禁止无参考直接生成（否则各镜头音色漂移）。
> 6. **BGM 分离 -> 视频提示词只规划视觉（重要）**：若选 B，BGM 由 ACE-Step 1.5 单独生成，因此**调用 `h3-prompt-writing` 写视频提示词时不可规划 BGM/旁白/对白的音频出现**（如"音乐渐强""旁白响起""对话切入"等），只规划镜头/动作/画面；音频在后期合成。若选 A，视频提示词可正常包含音频驱动指令，无需单独生成音频。
> 7. **删除自动剪辑 / 拼接**：本 skill 为单条视频，无剪辑；若有拼接需求改为剪辑思路。
> 8. **规划 / 分镜 / 排版等文本方法论沿用原 skill**。
> 9. **删除"表情图"相关提示词**（本 skill 不涉及）。

## Step 1：同语言理解用户意图
同原 skill（中文输入→中文提示词，英文→英文，日文→日文；保留影像结构：实拍空间出现平面手绘发光动画、与真实手/物接触、同一实体连续变形并逃跑、相机慢半拍追赶；蜡笔/粉笔/彩铅/粉彩质感；禁 3DCG/毛绒/均匀矢量/平滑霓虹/恐怖/巨眼/裂口/牙/威吓/跳吓；0–3s 必现接触；全片同一相邻空间连续；13–15s 空间级变形+可爱余韵）。
- ⏸ **确认门**：意图理解呈现后暂停，等你确认。

## Step 2：全新创意内容
同原 skill：每轮新组合，不复用参考 prompt 的暗房/PC/冰箱/星/心/蓝涡/蝶/蛇/章鱼/汉堡/巨眼/牙/暗结尾；新值：实拍空间、手绘初态、中心色、变形链、接触方式、追逐路线、拍摄者反应、空间级变形笑点。
- ⏸ **确认门**：创意呈现后暂停，等你确认。

## Step 3：必需输出格式
同原 skill：开头句 + 实拍空间与手机质感 + 0–3s + 3–6s + 6–10s + 10–13s + 13–15s + 手绘质感 + 相机追随 + 禁止事项 + 环境音。

## Step 4：提示词写作规则
同原 skill：可执行视频提示词而非散文；除非你要解释，先给提示词再给一句下一步建议；你明确确认 H3 生成前不生任何视频/图/音频/分镜。

## Step 5：交付 + 视频提示词（调用 h3-prompt-writing + 设置建议 + 交付物门）
你确认后，**不再由本 skill 直接写 H.3 提示词，改为调用 `h3-prompt-writing` skill**：
- **调用用户级 `h3-prompt-writing` skill**（纯文本、无需 API），以 STEP1–4 的同语言创意材料为输入，按其 **T2VA** 结构输出完整 H3 视频生成提示词（纯文生视频，无参考图）。
- 并附设置建议：
  - 本 skill 为**纯文生视频（T2VA）**：不接参考图；音频依总则「音频模式门」——模式=分离 时本视频提示词**仅规划视觉**，环境音/配乐后期合成（除非你自备环境音接端口）。
  - 时长 = 15s；分辨率 = 16:9（1920×1080）；其余你自定
  - 模型标注 MiniMax-H3；本地用 Wan/Animate2 文生视频亦可
  - 生成后自检：接触明显、连续变形、延迟追随、非恐怖手绘质感是否保留
- **本步骤产出**：完整 H3 视频提示词（T2VA）+ 设置建议。
- ⏸ **交付物门（可选）**：你确认提示词后自行在本地 H3 节点生成视频；**返回成片地址（可选）**。未返回也可直接结束。
