# Music Aesthetics MV（本地版 · 逐步确认式）

> 本文件由原始 skill `music-video-subtitle-generator` 改造为「本地版 · 逐步确认式」。
> **本地化改造总则 v2（纯提示词 · 逐步确认 · 交付物门）**
>
> **⏹ 门控硬规则（真停顿 · 已生效）**：本 skill 中每个 `⏸ 确认门` 与 `⏸ 交付物门` 均为**硬性停止点**，不是建议。固定执行顺序：① 仅输出当前步骤交付物（提示词 / 文本计划 / 分镜脚本等）；② **立即调用 AskUserQuestion 工具**，给三选项「✅ 确认，继续下一步」「✏️ 修改当前步」「⏸ 暂停 / 停止或换方向」；③ **等待用户回复**，本回复内**绝不可预生成任何后续步骤**（即使你觉得能一次写完）。任一 `⏸` 门不得跳过 / 合并，也不得仅用一句"请确认"文字代替——必须用 AskUserQuestion 真正阻塞。
> 1. **生图只给提示词，不调用任何生图工具**：参考卡等生图步骤只输出文生图提示词；用户自行用任意工具生成图像，并把**图像文件路径或地址返回给我**。本 skill 不硬编码任何 ComfyUI 工作流路径。
> 2. **每一步都确认 + 交付物门（核心规则）**：每个步骤产出后我都会暂停，等你「确认 / 修改」。生图步骤必须等你**返回图像地址**后，才进入视频提示词步骤（视频提示词以参考卡为参考图）。
> 3. **视频提示词调用所选中版本（`h3-prompt-writing` 英文版 或 `h3-prompt-writing-cn` 中文版）skill**：视频提示词均调用用户级所选中版本（`h3-prompt-writing` 英文版 或 `h3-prompt-writing-cn` 中文版）skill（纯文本、无需 API）来写；以你返回的参考卡为参考图，按其 I2VA / Ref2VA 结构输出完整 H3 视频提示词（逐镜头），并附端口 / 顺序 / 时长 / 分辨率设置建议与多镜头拼接顺序，由你在本地 H3 节点自行执行。 H3 特殊占位符 `<d>`/`</d>`、`<|lyrics_start|>`/`<|lyrics_end|>`、`<|caption_start|>`/`<|caption_end|>`、`<|cutoff|>` 及其固定 id 见 `h3-prompt-writing` 的「Special Tokens」节，写对白/歌词/字幕时严格照用。
> 4. **语音 / 音乐先询问（已升级为「音频模式门」）**：进入流程第一步（方向/简报锁定）时，必须先用 AskUserQuestion 问你**音频方案**，二选一：
> 5. **批次时长上限先问（贯穿分镜设计）**：同样在进入流程第一步（方向/简报锁定）时，用 AskUserQuestion 问你「本次一次生成几秒？」可选 5s / 10s / 15s（或自定），记为**批次时长上限**，并贯穿到本 skill 的分镜 / 镜头表设计步骤，使分镜在设计期就 ≤ 批次、无需事后强切。
>    - **A) 统一 H3 音频**：旁白 + 对白 + BGM 全部由 H3 原生音频驱动生成（最省事，音色/配乐与画面同步，无需外部文件）。
>    - **B) 分离生成**：旁白/对白只给提示词（你用任意 TTS 工具，推荐用「参考/音色克隆」模式保证跨镜头一致；不绑定 MOSS-TTS）、BGM 用 ACE-Step 1.5 本地生成（调用 `ace-step-1.5-prompt-writer` skill）、对白分别生成，后期合成。
>    - 记录你的选择，后续「视频提示词步骤」与「音频步骤」依此分支执行。
> 5. **旁白/对白一致性（分离模式必做）**：若选 B 且含旁白/对白，提醒你把【音色参考文件】（.wav/.mp3，代表目标音色）放到**当前项目文件夹（你运行本 skill 的工作目录）**，并在调用 TTS 时使用「参考模式 / 音色克隆」，确保多镜头音色统一；若你未提供该文件，先暂停请其提供，禁止无参考直接生成（否则各镜头音色漂移）。
> 6. **BGM 分离 -> 视频提示词只规划视觉（重要）**：若选 B，BGM 由 ACE-Step 1.5 单独生成，因此**调用 `h3-prompt-writing` 写视频提示词时不可规划 BGM/旁白/对白的音频出现**（如"音乐渐强""旁白响起""对话切入"等），只规划镜头/动作/画面；音频在后期合成。若选 A，视频提示词可正常包含音频驱动指令，无需单独生成音频。
> 7. **删除自动剪辑 / 拼接**：改为提供"剪辑思路"（ffmpeg 硬切 + 卡点对齐）。
> 8. **规划 / 分镜 / 排版等文本方法论沿用原 skill**。
> 9. **删除"表情图"相关提示词**。

## 核心原则（沿用）
- 先懂作品再选结构；最新确认创意意图；省略无关字段不填空占位。
- 屏幕文字是设计视觉层而非普通字幕（除非你要字幕）。
- 上传真歌/beat 为主音频床（除非要替换）。
- >15s 自然多镜头拼接：多镜头分镜 + 首尾帧续接 + 卡点硬切 + 全局 Master Audio 对齐。
- 你只要提示词→交付即止；要成片→确认后生成与拼接。

## STEP 1：预检锁定
同原 skill：画幅（9:16/16:9/1:1/21:9）、时长与多镜头结构（10s 测试/15s hook/30s+ 多镜头/自定义）、音乐窗口、歌词锁定（你提供则锁、无词则生原词后锁）、>15s 默认多镜头。
- ⏸ **确认门**：预检项呈现后暂停，等你锁定确认。

## STEP 2：创意契约
同原 skill：曲风/乐器/BPM 感/声腔/情绪温度、锁定歌词、时长与多镜头拆分、参考图角色（角色卡/场景卡/排版卡）、相机语言、排除项。
- ⏸ **确认门**：契约呈现后暂停，等你确认。

## STEP 3：参考图角色与场景采样（只给提示词 + 交付物门）
同原 skill 角色分配：排版参考卡（仅文字包装）、角色参考卡（身份/脸/发型/服装/比例/姿态）、场景参考卡（风格/空间/纹理/光）。
**调用用户级 `image-prompt-writer-local` skill** 生成富结构提示词：传入 场景类型=人像/风景/海报（按卡类型：角色参考卡=人像、场景参考卡=风景、排版参考卡=海报文字包装）、风格上下文=MV 统一影调、主体与要求=各卡（角色：身份/脸/发型/服装/比例/姿态；场景：风格/空间/纹理/光；排版：文字风格）。它返回「通用风格锚 + 每张参考卡四段式详描」，你原样呈现。
**本步骤产出**：每张参考卡的**文生图提示词**（来自上一步 skill 输出）。
- ⏸ **交付物门（必过）**：提示词给你后暂停。请你生成参考卡图像并**返回图像地址**（角色卡=角色参考、场景卡=场景参考、排版卡=文字风格参考）。收到后才进入 STEP 4–9。
> 本地化：删除"表情图"相关提示词。

## STEP 4：预设语法 / STEP 5：提示词模板 / STEP 6：音频连续
同原 skill（硬切仅、排版随拍、全局 Master Audio、五大连续性锁：嗓唇/节拍/色调/运动/排版拼接）。

## STEP 7：清单
同原 skill：>15s 是否自动多镜头、Master Audio 锁定、切点在歌词停顿/beat、相邻镜有衔接逻辑、硬切无 fade、参考卡互不串味、排版不挡眼/脸、全局影调一致。
- ⏸ **确认门**：清单呈现后暂停，等你确认。

## STEP 8：写画布（本地用文件节点）
同原 skill：把完整多镜头 prompt 脚本写入 `完整MV Prompt` 文本节点。
- ⏸ **确认门**：脚本呈现后暂停，等你确认。

## STEP 9：视频提示词（调用 h3-prompt-writing / h3-prompt-writing-cn + 设置建议 + 剪辑思路 + 交付物门）
**不再由本 skill 直接写 H3 提示词 / 调用编辑，改为调用所选中版本（`h3-prompt-writing` 英文版 或 `h3-prompt-writing-cn` 中文版）skill**：
- 输入：STEP3 返回的角色卡/场景卡/排版卡图像地址 + STEP8 多镜头脚本。
  - 🔸 **先问版本（h3-prompt-writing / h3-prompt-writing-cn）**：进入本步骤先问你使用哪个版本——`h3-prompt-writing`（英文版，说明与提示词均为英文）或 `h3-prompt-writing-cn`（中文版，说明为中文、占位符/标签保持英文）。两版本的「分镜 / 批次 / 参考图约定（含 motion-context 规则⑤）」完全一致，按你所选版本调用对应 skill。
  - ⚠️ **分镜 / 批次 / 参考图（严格遵循 `h3-prompt-writing` 约定）**：① 沿用起始门（简报）已确定的**批次时长上限**（批次时长由设备定，已在分镜设计前问过，本步不再重问）；② 把分镜按批次时长分组，**每批次产出一份独立 .md 文件**（命名 `batch_01.md`、`batch_02.md`…），文件内含该批次全部分镜的 H3 提示词 + 端口/顺序/时长/分辨率建议；③ 参考图一律用 `<Picture N>` 占位符指代，**严禁在提示词中写任何图像/视频文件路径或目录**（占位符 → 实际文件由你在 H3 节点侧按端口映射）。
  - 🔒 **批次打包（不重切分镜）**：把本 skill 分镜设计步骤产出并确认的分镜**按时长累加打包为批次**——同批次各镜时长之和 ≤ 批次时长上限（已在起始门确定），一个批次 = 一次 H3 生成 = 一份 `batch_XX.md`。**不重新切分已设计的分镜**，分镜的创意与音频时序在打包中保持不变。仅当某分镜本身 > 批次时长上限（设计期偶发）时，在生成层做机械分段（如 `Shot 3` → `3a` / `3b`，该分镜音频跨子段连续），不改其创意内容。**motion-context 在连续批次的衔接边界问**（见 h3-prompt-writing 规则⑤：跨段连续时启用，第 2 段起 22 帧重复 + 时间标注后延 0.917s、第 1 段不变）。
- **调用用户级所选中版本（`h3-prompt-writing` 英文版 或 `h3-prompt-writing-cn` 中文版）skill**（纯文本、无需 API），按其 I2VA / Ref2VA 结构，输出完整 H3 视频提示词（逐镜头 Shot1..N，含 Vocal/Typography/Visual/Camera/Transition）。
- 并附设置建议：
  - 参考图 = STEP3 返回的角色卡/场景卡/排版卡 → 按镜头需要接入 H3 节点「图像参考」端口（角色卡=角色参考、场景卡=场景参考、排版卡=文字风格参考）；多角色/多场景分别接入
  - 音频（依总则「音频模式门」分支）：模式=统一H3 时，Master Audio 由 H3 原生生成；模式=分离 时，本视频提示词**仅规划视觉**（不写 BGM 出现指令），Master Audio 由 `ace-step-1.5-prompt-writer` skill 生成 ACE-Step 1.5 提示词 后接「音频输入」端口。先问你「用云端生成 or 只给提示词」。
  - 时长 = 每镜头 2–5s（>15s 自动拆分 4–8 镜）；分辨率 = STEP1 画幅对应值；其余你自定
  - 模型标注 MiniMax-H3；本地用 Wan/Animate2 亦可（续帧用上一镜尾帧作 I2V 首帧）
- **本步骤产出**：完整 H3 视频提示词 + 端口/顺序/时长/分辨率设置建议。
- ⏸ **交付物门（可选）**：你确认提示词后自行在 H3 执行，返回成片地址（可选）。

**剪辑思路（替代 hub_video_edit）**
- 全局绑定一条 Master Audio；分段视频按时间戳对齐、卡点修剪/变速。
- 续帧：Shot B 同场景→取 Shot A 尾帧作 Shot B 首帧（I2V）；硬切→同角色卡/服装/光 + 同方向运动/匹配剪辑。
- 拼接工具建议：ffmpeg 硬切（无 fade/溶解）；统一 LUT + 35mm 颗粒掩盖批次色差。
- 交付：无缝完整 MV 文件。

## 失败恢复
同原 skill 思路：文字不清→减字；身份互换→加强；脸漂移→复用参考卡；风格弱→重写风格字段。
