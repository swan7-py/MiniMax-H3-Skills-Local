# Brand Promo Video Generator（本地版 · 逐步确认式）

> 本文件由原始 skill `brand-promo-video-generator` 改造为「本地版 · 逐步确认式」。
> **本地化改造总则 v2（纯提示词 · 逐步确认 · 交付物门）**
>
> **⏹ 门控硬规则（真停顿 · 已生效）**：本 skill 中每个 `⏸ 确认门` 与 `⏸ 交付物门` 均为**硬性停止点**，不是建议。固定执行顺序：① 仅输出当前步骤交付物（提示词 / 文本计划 / 分镜脚本等）；② **立即调用 AskUserQuestion 工具**，给三选项「✅ 确认，继续下一步」「✏️ 修改当前步」「⏸ 暂停 / 停止或换方向」；③ **等待用户回复**，本回复内**绝不可预生成任何后续步骤**（即使你觉得能一次写完）。任一 `⏸` 门不得跳过 / 合并，也不得仅用一句"请确认"文字代替——必须用 AskUserQuestion 真正阻塞。
> 1. **生图只给提示词，不调用任何生图工具**：每个生图步骤只输出文生图提示词；用户自行用任意工具生成图像，并把**生成的图像文件路径或地址返回给我**。本 skill 不硬编码任何 ComfyUI 工作流路径。
> 2. **每一步都确认 + 交付物门（核心规则）**：每个步骤产出后我都会暂停，等你「确认 / 修改」。凡涉及生成资产的步骤，必须等你**返回对应交付物（图像地址 / 视频地址 / 音频地址）**后，才进入下一步。典型链路：出静帧生图提示词 → 等你返回图像地址 → 再以其为参考图出视频提示词。
> 3. **视频提示词调用 `h3-prompt-writing` skill**：所有视频生成提示词，均调用用户级 `h3-prompt-writing` skill（纯文本、无需 API）来写；以你返回的图像为参考图，按其 I2VA / Ref2VA / T2VA 结构输出完整 H3 视频提示词，并附端口 / 顺序 / 时长 / 分辨率设置建议，由你在本地 H3 节点自行执行。
> 4. **语音 / 音乐先询问（已升级为「音频模式门」）**：进入流程第一步（方向/简报锁定）时，必须先用 AskUserQuestion 问你**音频方案**，二选一：
>    - **A) 统一 H3 音频**：旁白 + 对白 + BGM 全部由 H3 原生音频驱动生成（最省事，音色/配乐与画面同步，无需外部文件）。
>    - **B) 分离生成**：旁白/对白只给提示词（你用任意 TTS 工具，推荐用「参考/音色克隆」模式保证跨镜头一致；不绑定 MOSS-TTS）、BGM 用 ACE-Step 1.5 本地生成（调用 `ace-step-1.5-prompt-writer` skill）、对白分别生成，后期合成。
>    - 记录你的选择，后续「视频提示词步骤」与「音频步骤」依此分支执行。
> 5. **旁白/对白一致性（分离模式必做）**：若选 B 且含旁白/对白，提醒你把【音色参考文件】（.wav/.mp3，代表目标音色）放到**当前项目文件夹（你运行本 skill 的工作目录）**，并在调用 TTS 时使用「参考模式 / 音色克隆」，确保多镜头音色统一；若你未提供该文件，先暂停请其提供，禁止无参考直接生成（否则各镜头音色漂移）。
> 6. **BGM 分离 -> 视频提示词只规划视觉（重要）**：若选 B，BGM 由 ACE-Step 1.5 单独生成，因此**调用 `h3-prompt-writing` 写视频提示词时不可规划 BGM/旁白/对白的音频出现**（如"音乐渐强""旁白响起""对话切入"等），只规划镜头/动作/画面；音频在后期合成。若选 A，视频提示词可正常包含音频驱动指令，无需单独生成音频。
> 7. **删除自动剪辑 / 拼接**：改为提供"剪辑思路"。
> 8. **规划 / 分镜 / 排版等文本方法论沿用原 skill**。
> 9. **删除全部"表情图"相关提示词**。

## STEP 1：Intake 与简报
同原 skill：要求上传 logo/字体/配色/产品图/官网链接等可核实资产；确认时长（默认 15s）、画幅（16:9/9:16/1:1/4:3/3:4/参考）、campaign 焦点、渠道、语言。
- ⏸ **确认门**：用文字确认替代 choice card，呈现后暂停等你确认。

## STEP 2：品牌事实表
同原 skill：从用户资产/官网/媒体包提取 logo 变体、官方字体、主辅动态色、调性、产品名/功能/CTA/免责。禁用 logo 聚合站/粉丝复刻/AI 替代作为身份来源。

## STEP 3：来源清单（provenance）
同原 skill：记录每个身份资产来源与权利状态；未授权则标注为 unofficial concept。

## STEP 4：故事脊
同原 skill：按品类给 2–3 方向（AI/SaaS、实体产品、服务/公司、图像主导），推荐其一后确认。
- ⏸ **确认门**：方向呈现后暂停，等你选向并确认。

## STEP 5：精确 beat 规划
同原 skill：30fps 约定；15s→5–8 beat，30s→8–12 beat；每 beat 定义起止、视觉归属、主动作、产品证明、文案、色态、转场、运动意图。

## STEP 6：运动语言
同原 skill：用产品/UI/光/滚动驱动转场；2–5 个色态；每 beat 一个主动作；保留可读剪影与 logo 净空。

## STEP 7：硬确认门
同原 skill：生成前展示预生产包（来源摘要/事实表/方向/beat/文案/权利提示），用户确认后继续。
- ⏸ **确认门**：预生产包呈现后暂停，等你硬确认。

## STEP 8：本地产出资产（生图提示词 + 交付物门 → 视频提示词调用 h3-prompt-writing）
**本 skill 不调用任何 Hub / ComfyUI 生成**。改为按步骤交付提示词并等交付物：

1. **生图（只给提示词）**：生成/准备静帧、UI 板、产品主图、运动就绪故事图——**调用用户级 `image-prompt-writer-本地版` skill** 生成富结构提示词：传入 场景类型=海报/产品静物/风景（按资产类型选）、风格上下文=品牌统一调性、主体与要求=各资产。它返回「通用风格锚 + 每张图四段式详描」，你原样呈现（本步骤只输出该富提示词）。
   **严禁**：用生图重绘/近似 logo、字体、产品 UI、包装、吉祥物、真人——只用官方/用户授权资产或抽象运动层（遮罩/渐变/色场/网格/粒子/文字/图表/转场几何）。
   - ⏸ **交付物门（必过）**：提示词给你后暂停。请你用任意工具生成图像并**返回图像地址（作为后续视频参考图）**。收到后才进入第 2 步视频提示词。
2. **视频提示词（调用 h3-prompt-writing）**：以 STEP8.1 返回的图像（按镜头需要，可多张分别作为参考图1/参考图2）为参考图，**调用用户级 `h3-prompt-writing` skill**（纯文本、无需 API），按其 I2VA / Ref2VA / T2VA 结构输出完整 H3 视频提示词；并附设置建议：
   - 参考图 = STEP8.1 返回的图像 → 接入 H3 节点「图像参考 / image reference」对应端口
   - 音频（依总则「音频模式门」分支）：模式=统一H3 时，提示词内写品牌安全器乐/UI 音设计（generate_audio=true）；模式=分离 时，本视频提示词**仅规划视觉**，不写 BGM/旁白音频指令，音频后期合成。
   - 时长 = STEP1 确认值（默认 15s）；分辨率 = STEP1 画幅对应值；其余你自定
   - 模型标注 MiniMax-H3；本地用 Wan/Animate2 亦可（按节点调整首帧接入）
   - ⏸ **交付物门（可选）**：你确认提示词后自行在 H3 执行，返回成片地址（可选）。
3. **语音/音乐（先问云端）**：涉及语音/音乐时先问你「用云端生成 or 只给提示词」。若只给提示词，输出语音/BGM 风格提示词；不重复 soundtrack（原生音频与独立生成二选一）。其中 **BGM 部分优先调用用户级 `ace-step-1.5-prompt-writer` skill** 把音乐描述 + 可选带标签歌词改写成 ACE-Step 1.5 提示词；语音部分只给提示词（不绑定具体 TTS 工具，你用任意 TTS 生成）。

## STEP 9：交付前核对
同原 skill：身份资产来自核实/授权源；产品名/文案/CTA 与官方一致或标 concept；时长/画幅/语言匹配；logo 未拉伸；运动有清晰归属。

## STEP 10：交付 + 剪辑思路（替代自动剪辑）
- 成片按 beat 顺序拼接；仅保留最新批准资产。
- 字幕仅在用户明确要求时加。
- 工具建议：ffmpeg/本地剪辑软件硬切；保持品牌锁版与 logo 净空。

## 失败恢复
同原 skill 思路：错误/近似 logo → 换官方源或停问；仿冒产品 UI → 换授权媒体；生成资产不可用时停问授权原文件，绝不臆造。
