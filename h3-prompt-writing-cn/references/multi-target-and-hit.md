# 多目标打击与可读性（Multi-target hits and readability）

一段里要打多个目标、或要让"破坏结果"在画面里读得清楚时，以下四条。

## 1. 命中目标写死数量

- ❌ `接连拦腰切断悬浮的巨石碑` → 模型**只切一块**。
- ✅ `接连拦腰切断**三块**悬浮巨石碑` + `碑体**一块接一块**错位、下滑`。

**判据**：目标名词没有数量、也没有复数标记 → 模型按"一个"处理。要打几个就写几个（与"六枚羽刃"同理）。

## 2. 禁用「N 个相异 / 不同的方向」这类抽象量词，逐目标写死方位

- ❌ `羽刃自**三个相异的方向**分别劈开` → 实测**未被响应**：成片里三块碑被**同一个方向**切开。
- ✅ 逐目标写死：
  > 一路横掠，把左侧石碑**拦腰水平切断**；一路斜掠，把中央石碑**沿左上至右下斜向切断**；一路竖掠，把右侧石碑**自上而下竖直劈开**。

**判据**：方位词必须是模型能直接落到画面上的那几种——`水平 / 竖直 / 斜向 / 左上至右下 / 自下而上`。「相异」「不同」「各种」是抽象量词，模型不落地。

## 3. 空间布局禁「错落有致」式虚词，落到可执行的空间关系

- ❌ `三块巨石碑错落有致地悬浮`
- ✅ `自画面左侧向右依次斜列成一行，左侧一块最近、碑体最大，中央一块居中稍远，右侧一块最远、碑体最小，三块高低错开`

**判据**：布局句至少给出三层信息里的两层——**左右顺序 / 远近 / 大小 / 高低**。

## 4. 要露出主体的收尾，避免遮挡型破坏

"轰然坍塌"这类写法会带起大团烟尘，把随后要露出的主体盖住（实测：**烟尘挡人**，镜头推进看不清）。

- ✅ 改用**可读的物理慢动作**：`碑体沿切口错开，上半块顺着切面缓慢滑落、与下半块错位，石屑顺着切口簌簌落下`。
- ✅ 顺序写死：**先滑落 → 露出主体 → 镜头再推进**（不要让推近与坍塌抢同一拍）。
- 若因此需要更长时间，**加时长而不是加动作密度**（本例 9s → 10s，多出的 1s 全给"滑落 + 露出 + 推近"）。

**判据**：这一拍结束时要看清的那个东西，中间有没有东西会挡住它？有 → 换成不扬尘的破坏方式。

> 这四条与 `h3-video-prompt-cn/SKILL.md`「道具交接 / 朝向 / 破坏形状」节互补：那里管**单次破坏的形状要复刻攻击形状**，这里管**多个目标的数量、方位、布局与可读性**。
