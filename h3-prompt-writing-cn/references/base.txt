# 视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）

> 本指南对应 `h3-prompt-writing-cn` skill，目标是**用中文产出 H3 提示词**。代码块内的**字段名、占位符、标签、模式名、镜头词汇、关系标记**保持英文原样，请勿翻译；但**提示词内容（描述、动作、场景等）请用中文书写**。

## 1. 任务概述

- **T2VA**：从文本构建完整的视听时间线。
- **I2VA**：T2VA 主体 + 首帧指令 + 从首帧向前发展的视觉路径。
- **FL2VA**：T2VA 主体 + 首末帧指令 + 从首帧到末帧的连续路径。
- **L2VA**：T2VA 主体 + 末帧指令 + 从某个合理的先前状态收束到末帧的路径。

## 2. 最终提示词结构

### 2.1 第一部分是图像对齐指令

**T2VA** 没有图像对齐指令，直接以三个核心字段开始。

**I2VA** 始终使用：

```text
目标视频中，于 0.00 秒处，<Picture 1>（来自 [Shot 1]）被完整参考。
```

**FL2VA** 始终使用：

```text
参考图如何与目标视频对齐 —— Picture 1（来自 Shot 1）与目标视频的 0.00 秒标记对齐；Picture 2（来自 Shot N）与目标视频的 S.SS 秒标记对齐。
```

**L2VA** 始终使用：

```text
参考图如何与目标视频对齐 —— <Picture 1>（来自 [Shot N]）与目标视频的 S.SS 秒标记对齐。
```

此处 `N` 是实际末镜的索引，`S.SS` 是有效视频时长，格式化为恰好两位小数。该指令必须是最终提示词的第一行，其后空一行再接核心字段。

### 2.2 第二部分是三个核心字段

```text
integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: ...
```

- **integrated_multimodal_description**：描述沿时间线的视觉、动作、镜头、说话人、对白、歌唱与画内音频。
- **overall_soundscape**：概括整段视频的环境声、物理动作声与非语言人声。
- **non_diegetic_music**：描述角色听不见、只有观众能听到的背景音乐。

## 3. 如何将关键帧纳入多模态描述

### 3.1 I2VA：从图像开始并向前发展

`<Picture 1>` 是视频在 0.00 秒的实际首帧，属于 `[Shot 1]`。描述应先用图像建立风格、主体、构图与场景锚点，再描述后续动作。角色身份、服装、颜色、关键物体与空间关系应保持一致。

推荐结构：**首帧锚点 → 动作起始 → 连续发展 → 结果或反应**。

### 3.2 FL2VA：描述首末帧之间的路径

Picture 1 是开头，Picture 2 是结尾。聚焦主体如何移动、姿态如何变化、物体如何被操控、构图如何演变、场景或光线如何过渡。

FL2VA 通常偏好单镜，以便模型从首帧连续插值到末帧。仅当明确指定时才用多镜。末帧必须由视频结尾的最后一个 `[Shot N]` 抵达。

推荐结构：**首帧状态 → 可观测的中间变化 → 逐渐收窄的差异 → 末帧状态**。

### 3.3 L2VA：推断开头并落定在结尾图像

`<Picture 1>` 是视频的末帧，属于最后的 `[Shot N]`；它并非天然属于 Shot 1。根据用户意图与末帧推断一个合理的先前状态，再描述角色、物体、镜头与场景如何逐渐接近参考图像。

推荐结构：**合理的先前状态 → 明确动作与过渡路径 → 末镜中逐渐收束 → 末帧落定**。

## 4. 如何撰写三段共享核心内容

### 4.1 沿时间线展开多模态描述

`integrated_multimodal_description` 是改写提示词的主体。每个细节都应对应可见或可听的内容：视觉风格、初始构图、主体外观与位置、场景与关键道具、动作与反应、镜头切换、口语语言，以及同步的画内声音。

在 `[Shot 1]` 开头说明整体风格与初始构图。常见风格有 `Cinematic`、`live-action`、`2D-animated`、`3D CG`、`claymation`、`watercolor`、`vintage film`。关键帧任务从参考图推导风格；T2VA 从用户文本选择。

```text
[Shot 1] Live-action, cinematic, 中景框入……
```

### 4.2 分镜与切点

不要给首镜加时间戳。后续镜用顺序镜号，且每段以严格递增的切点在视频时长内开始：

```text
[Shot 2] At 00:03.500，镜头切到……
```

普通切点用 `the camera cuts to`、`the shot cuts to`、`the shot transitions to`、`the shot changes to` 或 `the shot switches to`。用户明确要求时，也可用 cross-dissolve、fade 或 wipe。切点应引入主体、空间、状态、视角或时间的新信息。若只需改变距离或微小角度，优先用镜头运动。

### 4.3 镜头运动：运动类型 + 幅度 + 速度

完整的镜头运动表达有三个维度：**运动类型**定义镜头如何移动，**幅度**定义构图变化的范围，**速度**定义该变化的节奏。仅当有意义时才加幅度与速度；中等幅度与正常速度通常省略。

| 维度 | 可用表达 | 说明 |
|------|----------|------|
| 运动类型 | `Zoom In / Zoom Out` | 机身不动，焦距变化 |
| 运动类型 | `Push In / Pull Out` | 镜头前 / 后移动 |
| 运动类型 | `Pan Left / Pan Right` | 机身不动，镜头水平转动 |
| 运动类型 | `Truck Left / Truck Right` | 镜头水平平移 |
| 运动类型 | `Tilt Up / Tilt Down` | 机身不动，镜头垂直转动 |
| 运动类型 | `Pedestal Up / Pedestal Down` | 整个镜头上 / 下移动 |
| 运动类型 | `Arc Shot` | 镜头绕主体做弧线运动 |
| 运动类型 | `Tracking Shot` | 镜头跟随移动主体 |
| 运动类型 | `Static Shot` | 镜头位置与焦距保持不变 |
| 运动类型 | `Shake Slightly / Shake Strongly` | 轻微 / 强烈镜头抖动 |
| 运动类型 | `POV` | 主体视角 |
| 运动类型 | `Roll Clockwise / Roll Counterclockwise` | 镜头绕光轴顺时针 / 逆时针翻滚 |
| 幅度 | `with small amplitude` | 小范围变化 |
| 幅度 | `with large amplitude` | 大范围变化 |
| 速度 | `at slow speed` | 慢速运动 |
| 速度 | `at fast speed` | 快速运动 |

镜头运动应作为镜内自然的中文动作书写，而非堆在句尾的孤立标签：

```text
镜头以慢速小幅推近她手中叠好的信。
镜头以快速大幅向右平移，露出敞开的门道。
镜头保持静止，跑步者退出画面。
```

### 4.4 说话人、对白与歌唱

会说话、歌唱或产生画外人声的主体使用稳定 ID，如 `(S1)`、`(S2)`。多个已编号说话人一起说或唱时，用复合 ID 如 `(S1,S2)`。说话人跨镜保持同一 ID；从不发声的角色不分配说话人 ID。

说话人首次出现时，从视觉与音频语境提供足够的稳定身份信息，如角色类型、年龄、性别、是否在画面中、音高、音色、语速或口音。将说话人的身份短语、ID、动作与语气放在 `<d>` 之外；`<d>` 内部只放语言标签与用户提供的实际口语内容。逐字保留每个原词与标点；不要翻译或改写。

```text
那位嗓音轻柔气声的年轻女子 (S1) 说道：<d>[English] I get off at the next station.</d>
两个孩子 (S1,S2) 一起喊道，<d>[English] Wait for us!</d>
```

画外音用精确的 `says in an off-screen voiceover`。每个画外音 `<d>` 块之后，立即说明对应画面角色嘴唇保持闭合：

```text
那名男子 (S1) 以画外音说道：<d>[English] I still remember that road.</d> 同时他的嘴唇保持完全闭合。
```

同一句对白或歌词跨切点时，在两部分连接处用 `<scenetrans>` 并明确说明音频跨切点连续。`<cutoff>` 用于语音被视频结尾截断时。连续性可用 `continues seamlessly across the cut`、`continues uninterrupted into the next shot`、`carries over from the previous shot`、`remains audible across the transition` 表达。

### 4.5 屏幕可见文字

任何真正出现在画面上的横幅、标牌、标签、字幕或霓虹文字，放在半角双引号内。逐字保留原文与标点，不翻译。

```text
A red neon sign reading "营业中" glows above the doorway.
```

### 4.6 overall_soundscape

用 1–4 句中文、一个连续段落概括整段视频的环境声、物理动作声与非语言人声，如风、雨、交通、脚步、布料移动、撞击、呼吸、笑声或喘息。对白、歌唱与画内音乐已属于多模态描述，不要在此重复。仅当用户明确要求整段视频完全静音时用 `N/A`。

```text
overall_soundscape: 平稳的雨点敲打着咖啡馆的窗户，下方持续着低沉的室内环境底噪。门铃响了一声，接着是潮湿的脚步声与椅子轻微的刮擦声。
```

### 4.7 non_diegetic_music

用 1–3 句中文描述角色听不见、只有观众能听到的背景音乐。聚焦配器、速度、节奏与动态变化；不要用抽象情绪词或解释配乐的情感功能。角色能听到的歌唱、乐器、广播、电视或手机音乐是画内事件，应出现在多模态描述中。无观众配乐时用 `N/A`。

```text
non_diegetic_music: 缓慢节奏下的稀疏钢琴音符，加入持续低沉的弦乐，音量逐渐增大后淡出。
```

## 5. 案例

### 案例 1：T2VA

无参考图，直接从文本构建完整时间线。可补充与用户意图一致的场景、角色、动作与声音细节。

```text
integrated_multimodal_description: [Shot 1] Live-action, cinematic, 中景框入一名面包师在日出前拉开街头小面包店的百叶窗。镜头以慢速小幅推近，那位嗓音平静略带沙哑的中年面包师 (S1) 把一条新鲜面包放上木台，说道：<d>[English] First batch of the morning.</d> [Shot 2] At 00:05.000，镜头切到特写，蒸汽从切开的面包上升，而面包师的最后一句从前一镜延续过来。

overall_soundscape: 安静的街道上木百叶窗吱呀拉开，店内托盘轻轻碰撞。门铃响一声，接着是轻脚步声与面包被切开的清脆声响。

non_diegetic_music: 中速的柔和木吉他节奏，加入稀疏的立式贝斯音符，结尾轻轻淡出。
```

### 案例 2：I2VA

先写首帧指令，再以 Picture 1 中的主体、构图与场景作为 Shot 1 的起点，描述场景如何继续发展。

```text
目标视频中，于 0.00 秒处，<Picture 1>（来自 [Shot 1]）被完整参考。

integrated_multimodal_description: [Shot 1] Live-action, cinematic, <Picture 1> 中那名年轻女子仍坐在被雨覆盖的列车窗边，保留她的外貌、服装、座位与车厢布局。镜头以慢速小幅向右平移，她将目光从叠好的信上抬起，望向掠过的城市灯火。她的倒影在玻璃上移动，而那位嗓音轻柔气声的年轻女子 (S1) 说道：<d>[English] I get off at the next station.</d> 她顺着原有折痕折好信。

overall_soundscape: 列车车轮在低沉的通风嗡鸣下发出稳定金属节奏。雨点敲打窗户，纸在她手中轻轻作响。

non_diegetic_music: 缓慢节奏下持续的大提琴音符，间以稀疏钢琴音，音量逐渐减弱。
```

### 案例 3：FL2VA

两张图像分别锚定开头与结尾。主体不应重复两份静态图像描述，而应提供连接它们的运动路径。以下示例为 8 秒单镜。

```text
参考图如何与目标视频对齐 —— Picture 1（来自 Shot 1）与目标视频的 0.00 秒标记对齐；Picture 2（来自 Shot 1）与目标视频的 8.00 秒标记对齐。

integrated_multimodal_description: [Shot 1] Live-action, cinematic, 一名被雨淋湿的骑行者以 Picture 1 确立的姿势与构图起始，在银色自行车旁举着一把收起的黑伞。镜头以慢速小幅拉远，她松开自行车把手，将伞举过肩头，向上推压伞柄直到伞盖展开。水珠从展开的布料滚落，她走到伞下，将手柄转到最终角度，并定格为 Picture 2 在镜头结尾确立的姿势、间距与构图。

overall_soundscape: 雨持续落在人行道上，接着是伞骨的金属咔嗒声与伞盖展开的轻响。水珠从车架滴落，远处车流经过。

non_diegetic_music: N/A
```

### 案例 4：L2VA

图像只锚定最终时刻。先建立兼容的更早状态，再让动作、物体状态与构图在末镜逐渐落定到 Picture 1。以下示例为 6 秒单镜。

```text
参考图如何与目标视频对齐 —— <Picture 1>（来自 [Shot 1]）与目标视频的 6.00 秒标记对齐。

integrated_multimodal_description: [Shot 1] Live-action, cinematic, 特写开场：一只完好的玻璃杯靠近深色木桌边缘，而 <Picture 1> 中可见的同一只手与袖子从右侧靠近。镜头以慢速小幅推近，指尖击打杯沿。玻璃杯倾斜、坠落，以尖锐撞击砸向地面；裂纹蔓延，碎片向外滑开。接近结尾，移动碎片失去动量，定格为 <Picture 1> 确立的精确破碎排列、手部位置、镜头角度、光线与最终构图。

overall_soundscape: 指尖轻敲玻璃杯，随后它划过桌面、坠落并以刺耳碎裂声破碎。小碎片四散，逐渐停止在地面上滑动。

non_diegetic_music: 缓慢节奏下的低沉电子脉冲，于玻璃破碎后立即结束。
```
