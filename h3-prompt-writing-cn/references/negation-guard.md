# 否定式闸门：裸否定的监控与正向化

> 来源：H3 运镜对照测试（用户指出"稳定镜头里仍有 '不抖动''不晃动' 之类的描述，可能是画面产生抖动的原因"）
> H3 **没有负面提示词**：写"不晃动"给出的是一条"点名了却无替代"的空指令；更可能**诱导**该现象出现。

---

## 一、判定规则（两级）

| 级别 | 判据 | 处理 |
|---|---|---|
| **L1 裸否定（硬拦）** | `不 / 没有 / 无` **直接修饰运动或状态**，且**没给出该维度的正向取值** | **必须改写**，否则拒绝提交 |
| **L2 待确认** | 出现 `不 / 没 / 无` 但不在 L1 词表里 | 列清单交人工判断（**"不同""不仅""不断"是安全的**） |

**白名单（含"不"但安全）**：不同、不仅、不但、不断、不止、不妨、不足、不良、不少、无论、无需…

> ⚠️ **不要用"朴素的字符级子串拦截"**（见到 `不/无/没/非` 就拒）。
> 那会误伤"**不同位置**""**不仅**"，并逼出"稳住、维持推掌姿"这种绕口的改写。
> **必须用"词表 + 白名单"两级判定。**

## 二、L1 词表（裸否定）

```
运动/位移：不移动 不动 不晃 不晃动 不抖动 不抖 不摇 不摇晃 不摆动 不摆转 不转身 不转 不旋转
          不俯 不仰 不倾 不偏 不折返 不停顿 不停 不切换 不改变 不变化 不变动 不移 不走 不跑
存在/呈现：不出现 没有晃动 没有抖动 没有位移 没有变化 没有视差 无晃动 无抖动 无位移 无视差 无变化 无遮挡
恒定陈述：保持不变 固定不变 始终不变 全程不变 恒定不变
元信息：  不约束 不因它而 不因此
```

**注意「恒定陈述」也归 L1**：`保持不变 / 固定不变` 虽不是"点名不要什么"，但读起来仍是"以否定兜底"；
正向写法更省事、也更不容易被模型当成"某个可以变的东西"——**直接给出取值**："全程固定在同一点""全程恒定""锁定在同一档位"。

## 三、正向化替换表（L1 → 正向写法）

| ✗ 裸否定 | ✓ 正向写法 |
|---|---|
| 机位保持在原地不动 / 机位本身不移动 | 机位位置全程固定在同一点 |
| 机位只横向侧移、不摆转 | 机位沿横向侧移，镜头朝向全程锁定在同一方向 |
| 机位平滑漂浮、没有晃动 | 机位平滑漂浮，画面全程平稳顺滑 |
| 镜头焦距保持不变 | 焦距全程锁定在同一档位 |
| …的位置与大小保持不变 | …的位置与大小全程恒定 |
| 取景保持不变 | 取景全程恒定 |
| 分毫不变 | 全程恒定 |
| 定格不动 | 定格在同一瞬间的形态上 |
| 近景与远景之间没有视差 | 画面呈平面等比放大，纵深关系保持原有比例 |
| 中途不切换 | （删——`一镜到底` 已表达） |
| `<Picture N> 不约束构图与机位，镜头不因它而调整取景` | `<Picture N>` 仅作环境形制与光位氛围的参照；构图与机位一律以本提示词的镜头描述为准 |

## 四、落地方式（三层防复发）

1. **源头正向化**：写提示词时按上表直接写正向句；**camera DSL 的 negative clarifier 必须转写**（见 `camera-and-lora.md` §1 的对照表）；
2. **提交前强制闸门**：跑批脚本在提交前调用闸门脚本，**L1 命中即拒绝提交**并打印修改指引；
3. **报告可视化**：出报告时同时跑一次闸门，把结果标在报告顶部（✓ 通过 / ⛔ 列出违规镜）。

**闸门脚本接口**（本项目实现，可移植）：
```bash
python lint_negation.py                # 扫描全库并分类报告（L1 硬拦 / L2 待确认）
python lint_negation.py --fix          # 应用正向化替换表（自动备份）后复扫
python lint_negation.py --quiet        # 只输出结论，退出码 0=干净 / 1=有裸否定（供提交脚本调用）
python lint_negation.py --shots=A1,B3  # 只查指定镜
```
**批量替换前务必先备份**；替换后**必须再做一次人工复核**——自动替换只保证"没有裸否定字面"，不保证语义无损。

## 五、待验证的假设

> **"提示词里出现 '不晃动'，可能反而诱发画面抖动"**

该假设符合"提到 X 会提高 X 的出现概率"的直觉，但**尚未验证**——原因也很实际：
相机抖动目前**没有可靠的量化指标**（见 `director-shot-review` 的指标可用性清单）。
若要验证，只能设计**同镜同种子的对照**（稳定器镜头：写"没有晃动" vs 写"画面全程平稳顺滑"），**靠目视判**。
