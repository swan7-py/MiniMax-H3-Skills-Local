# 全参考模式改写输出格式指南

> 本指南对应 `h3-prompt-writing-cn` skill，目标是**用中文产出 H3 提示词**。代码块内的**字段名、占位符、标签、模式名、关系标记**保持英文原样，请勿翻译；但**改写段落的内容（描述、动作、场景等）请用中文书写**。

本指南说明全参考模式下改写输出如何组织与书写。

改写六段的内容均用中文书写。仅在对白、歌词（在 `<d>` 内）以及场景中可见的文字处保留原始语言。

**描述详尽度**：让 `detailed_description` 尽可能详细、明确。对每个分镜，清楚建立当前构图、主体外观与位置、环境与光线、动作与状态变化、镜头运动、当前声音，以及被参考内容实际出现或生效的时点。避免把描述简化成剧情摘要或参考关系列表。

> 分镜、镜头运动、说话人、对白、普通声音的基格式与视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）共享。本指南聚焦全参考模式特有的参考标签、分析段落与格式差异。

## 1. 整体结构

完整的改写输出由六段按以下顺序组成：

| 段落 | 用途 |
|------|------|
| `subject_definitions` | 定义被参考内容及其参考标签 |
| `summary` | 概括任务类型、目标视频与主要参考关系 |
| `retention_analysis` | 描述被参考内容如何被保留、转移或复用 |
| `detailed_description` | 按播放顺序描述视觉、动作、镜头、声音与对白 |
| `overall_soundscape` | 概括环境声与物理声音 |
| `non_diegetic_music` | 描述只有观众能听到的背景音乐 |

## 2. 参考标签与定义（subject_definitions）

全参考改写使用四类标签来标识被参考内容的来源与角色：

| 标签 | 含义 |
|------|------|
| `<Subject N>` | 从参考资产抽象出的、可在目标视频中复用或修改的可见内容 |
| `<Picture N>` | 用作具体目标帧或分镜规划锚点的参考图像 |
| `<Video N>` | 提供剪辑源、续写起点或整段视频时间结构的参考视频 |
| `<Audio N>` | 被复制或参考的音频信号 |

> 一旦某个参考标签被分配给一段内容，它在 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 与音频段落中保持同一含义。

`subject_definitions` 定义后续需单独追踪的每段被参考内容，如一个人、一个环境、源视频的结构或一条音轨。每项单独成行，说明其标签指代什么、参考角色，以及要遵循的主要特征；当出处需显式说明时，点明对应的源资产。若 `<Picture N>` 或 `<Video N>` 只是标识另一被参考项的来源、之后不会单独分析或使用，在该项的 definition 内引用即可，不必另起一行。`retention_analysis` 记录每项被参考内容出现的位置，以及它是被完整保留、部分保留、转移还是复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用的可见内容，包括：

- 人物、动物或物体
- 场景、背景或环境
- 服装、道具、界面或视觉效果
- 风格、动作、表情或姿态

它代表目标视频中实际会用到的一个内容单元，而非源文件本身。一个 subject 可由多个参考资产定义，一个参考资产也可提供多个 subject。

```text
<Subject 1> 是 <Picture 1> 中的年轻女子，留深长发，穿蓝色开衫，戴细银项链。
```

当同一 subject 来自多个资产时，合并来源并说明每个资产提供什么：

```text
<Subject 1> 是那位外貌来自 <Picture 1>、行走动作来自 <Video 1> 的女子。
```

### 2.2 `<Picture N>`

当参考图像本身作为某镜的首帧、关键帧、末帧、剪辑关键帧或构图锚点时，使用独立的 `<Picture N>`：

```text
<Picture 2> 是 [Shot 1] 的首帧，画面为一名女子坐在咖啡馆窗边。
```

若图像仅用于定义角色、场景、服装或风格，不要创建独立的 picture 条目，而是在对应的 `<Subject N>` definition 内引用图像来源。

当图像作为分镜规划 / 故事板参考时，说明它映射到哪些镜，以及提供什么规划信息：

```text
<Picture 3> 是 [Shot 1] 与 [Shot 2] 的分镜规划参考，定义其视角、主体位置与镜头顺序。
```

### 2.3 `<Video N>`

`<Video N>` 保留给整段视频关系，例如：

- 剪辑原始视频
- 从原始视频结尾续写
- 参考原始视频的镜头运动、切点、节奏或时间结构

```text
<Video 1> 是目标视频剪辑的源视频。
```

若参考视频中的人物、物体、场景、动作或效果被复用为可见内容，仍归在 `<Subject N>` 下。`<Video N>` 标识资产或结构来源，不替代 subject 标签。

### 2.4 `<Audio N>`

`<Audio N>` 代表独立的音频资产，或参考视频中启用的同步音轨。常见用途包括：

- 复制音频信号的全部或部分
- 参考背景音乐风格
- 参考说话人的音色与语气
- 使用原始音频中的对白、歌词或音效
- 参考节拍、节奏或音频连续性

当某个 `<Audio N>` 明确对应目标说话人时，在 definition 中复用该说话人的全局 ID：若该说话人映射到已定义的 subject，写 `<Subject N> (Sx)`；否则用稳定的嗓音描述后跟 `(Sx)`。ID 来自目标视频的全局说话人顺序，不在音频 definition 中独立分配或重新编号。说话人编号规则见 5.4 节：

```text
<Audio 1> 是 <Subject 1> (S1) 的音色参考。
```

当一个音频资产担任多个角色时，用一句自然的句子描述这些角色，不要另建子段落。

### 2.5 同一条参考视频的视觉与音轨

`<Video N>` 与 `<Audio N>` 独立编号。每个索引只表示该标签在各自类别中的顺序，不编码两类之间的配对。因此同一参考视频可对应 `<Video 1>` 与 `<Audio 2>`；不同索引不妨碍它们来自同一源资产。

普通参考视频不会因为文件含声音就自动创建 `<Audio N>`。

`<Audio N>` definition 主要说明音频的角色，不必点名它来自哪个 `<Video N>`。仅当需要消除出处歧义时才说明共享来源，例如：

```text
<Video 1> 是目标视频剪辑的源视频。
<Audio 2> 是 <Video 1> 的同步音轨，并在目标视频中被复用。
```

## 3. summary

本段用一段简短的中文概括目标视频及其参考关系。以方括号内的任务类型前缀开头：

```text
[reference generation] ...
[video editing + reference generation + audio reuse] ...
```

按每个参考资产在目标视频中的实际角色选择任务类型：

| 任务类型 | 何时使用 |
|----------|----------|
| `keyframe completion` | 图像作为目标视频的首帧、关键帧、末帧、剪辑关键帧或其他具体帧锚点 |
| `reference generation` | 图像、视频或音频资产为角色、场景、风格、动作、镜头运动、故事板等提供生成指导，但不作为具体帧，也不作为被剪辑或续写的源视频 |
| `video editing` | 直接修改一个已有的源视频；编辑图像或在静态关键帧之间生成不属于此类 |
| `video continuation` | 新内容从已有源视频继续、延伸、恢复或过渡 |
| `audio reuse` | 同一音频信号被全部或部分复用 |
| `audio reference` | 音频信号不被直接复制；只参考其音乐风格、音色、对白或歌词内容、音效质感、节拍或连续性 |

当一项任务满足多种关系时，用 ` + ` 组合任务类型，不要重复。例如，从源视频续写同时用图像作为末帧，写作 `[video continuation + keyframe completion]`。编辑源视频同时保留其原始音频，可写作 `[video editing + audio reuse]`。

仅因存在视频或音频，不会自动产生对应任务类型。若参考视频只提供镜头运动、切点或节奏，通常属于 `reference generation`。仅当该视频被直接剪辑或续写时才用 `video editing` 或 `video continuation`。

编辑源视频时，若其原始音频仍可被听见，同时用 `audio reuse`。从源视频续写但不直接复制音频信号时，若新音频只延续原音轨的可听特征，用 `audio reference`。

summary 使用先前定义的 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 标签描述主要 subject、镜头流向与参考资产角色。不要在本段引入新的参考标签。

对于视频编辑任务，任务类型前缀之后以如下方式开始 summary：

```text
目标视频是 <Video 1> 的剪辑版本。
```

## 4. retention_analysis

本段描述每段被参考内容在目标视频中如何被保留、转移、复制或参考。每个参考标签一行，保留 `subject_definitions` 中确立的含义。

### 4.1 可见内容

`<Subject N>`、`<Picture N>`、`<Video N>` 使用以下关系标记。这些标记是输出格式中固定的英文值：

| 关系标记 | 含义 |
|----------|------|
| `fully_preserved` | 被参考内容的定义角色被完整保留 |
| `partially_preserved` | 被参考内容仍被使用，但某些定义特征被改变或仅部分保留 |
| `attribute_transfer` | 被参考特征被转移到另一个可识别的目标 subject |
| `weak_reference` | 仅保留风格、类别、构图或氛围上的宽泛相似 |

Subject 条目：

```text
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...
```

Picture 条目：

```text
<Picture 2> ([Shot 1] first frame): fully_preserved - ...
```

Video 结构条目：

```text
<Video 1> (cut and pacing structure): weak_reference - ...
```

### 4.2 音频

`<Audio N>` 使用以下关系标记：

| 关系标记 | 含义 |
|----------|------|
| `fully_copy` | 完整源音频作为目标视频的完整最终音轨 |
| `partially_copy` | 只复制时间线的部分或选中的音频层，或复制后增、删、换其他声音 |
| `reference` | 信号不被直接复制；只参考音色、节奏、音乐风格、对白内容或音效质感 |
| `weak_reference` | 仅保留类别或氛围上的宽泛相似 |

```text
<Audio 1>: fully_copy - <Audio 1> 以 1:1 方式复用为目标视频的完整最终音轨。
```

```text
<Audio 2>: reference - 目标说话人跟随 <Audio 2> 的音色与克制演绎，但不复制原始信号。
```

每个关系标记只在 `subject_definitions` 中已为该标签定义的参考角色内选择。不要把目标视频中新加的动作、背景或剧情事件当作参考保真度下降。

## 5. detailed_description

这是全参考改写的正文。按目标视频播放顺序逐镜描述视觉、动作、声音与对白，并在适用处插入参考标签。

### 5.1 基本格式

基本格式遵循视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）：

- 正文用中文书写。保留对白、歌词与可见文字的原始语言。
- `[Shot 1]` 标记开场镜，无时间戳。后续镜用 `[Shot N] At MM:SS.mmm, ...` 标记切点。
- 镜头运动作为当前镜内自然的中文书写，包括需要表达的运动类型、幅度与速度。
- 给发声来源稳定的 `(S1)`、`(S2)` 及后续 ID。对白与歌词写作 `<d>[Language] ... </d>`。
- 对白跨切、被视频结尾截断的语音、跨镜连续音频，分别用 `<scenetrans>`、`<cutoff>` 及对应的连续性描述。

关于镜头词汇、群体说话、画外音、跨切对白与可见文字的完整规则与示例，见视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）。

### 5.2 全参考模式差异

| 维度 | T2VA | 全参考模式 |
|------|------|------------|
| 主字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开头 | 写在 `[Shot 1]` 之后 | 在 `[Shot 1]` 之前用一两句中文建立 |
| 参考信息 | 不使用全参考标签 | 在首次出现及角色适用处插入 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` |
| 音频关系 | 描述目标视频自身的声音 | 在对应镜或音频阶段引用 `<Audio N>`，并说明信号是被复制还是被参考 |

开头示例：

```text
目标视频采用电影感、文学化的音乐 MV 风格，光线柔和、色调略微去饱和。
[Shot 1] 场景从一条拥挤的城市街道展开……
[Shot 2] At 00:09.000，镜头切到极特写……
```

对于生成任务，`detailed_description` 通常为 350–500 个中文字。对白密集的内容优先贴合完整的口语时间线，而非机械地凑到字数。视频编辑描述随源视频复杂度伸缩，不必遵循生成任务的范围。单镜不会自动证明可以更短描述；按各自信息量将细节分配到多个镜。

### 5.3 在分镜中使用参考标签

在某个重要 `<Subject N>` 首次清晰出现时，在镜中实际可见的范围内描述其被参考的特征、在画面中的位置与当前动作。后续镜继续使用同一标签，不再重新定义该标签指代什么。

用自然措辞描述具体的帧锚点：

```text
镜头从 <Picture 1> 开始
镜头的关键帧对应 <Picture 2>
镜头结束于 <Picture 3>
```

剪辑或续写原始视频时，在源状态、结构或续写关系适用的位置自然引用 `<Video N>`。在音频关系活跃的分镜或语义阶段引用 `<Audio N>`。

### 5.4 说话人、音频源与对白

基本说话人 ID 与 `<d>` 格式遵循 T2VA。当被参考 subject 实际发声时，同时保留视觉参考标签与说话人 ID：

```text
<Subject 2> (S1) 转向女子说道，<d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>
```

`<Subject N>` 标识被参考 subject，而 `(Sx)` 标识实际说话人。当 subject 发声时，写 `<Subject N> (Sx)`。若同一 subject 画外发声，保持同一形式并标记为 `off-screen`。当说话人不对应已定义的 subject 时，用稳定的嗓音描述后跟 `(Sx)`。

当文字内容只是直接复用的 BGM 或完整音轨中的提示、且没有人、角色、旁白或其他独立发声源实际产生它时，用 `<Audio N>` 作为可听来源，不要额外编造 `(Sx)`。若由具体的人、角色、旁白或其他独立发声源产生声音，为该来源分配并复用 `(Sx)`：

```text
当 <Audio 1> 播放到 <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d> 这句时，<Subject 1> 做出相应手势，但不作为独立发声源。
```

当参考音频中的对白、旁白或歌词被直接复用，或输入提示明确要求重新演绎时，在 `<d>` 内逐字保留源文字与原始语言。对听不清的片段写 `[unclear]`，不要猜测或改写。将标点规范化为表达句子所需的基本书面标点，如 `,`、`.`、`?`、`!`；去除重复的波浪号、emoji、项目符号，以及重复或装饰性标点。在 `</d>` 之前，用 `.`、`?`、`!` 分别结束完整的陈述、疑问与感叹。

仅当参考音色、节奏、情绪或语气时，不要把参考音频的原始对白带入目标视频。

按目标视频中实际发声事件的顺序一次性分配 `(Sx)`。在 `detailed_description` 的每个实际发声事件处复用对应 ID；在 `subject_definitions` 中绑定到目标说话人的 `<Audio N>` definition 也复用同一 `(Sx)`，但绝不独立分配新的。不要在 `retention_analysis` 中写 `(Sx)`。仅存在于直接复用的 BGM 或完整音轨中的文字提示用 `<Audio N>`；由具体的人、角色、旁白或其他独立发声源实际产生的声音用 `(Sx)`。

## 6. overall_soundscape 与 non_diegetic_music

这两类声音的定义遵循视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）。

`overall_soundscape` 概括整段视频的环境声与物理声音。对白、歌唱及与某镜同步的声音事件仍留在 `detailed_description`：

```text
overall_soundscape: 安静的室内环境底噪与低沉的通风嗡鸣贯穿整段视频。
```

`non_diegetic_music` 描述角色听不见、只有观众能听到的背景音乐。有音乐时，说明其配器、速度与动态发展：

```text
non_diegetic_music: 一段克制的钢琴独奏配乐，速度缓慢，下方铺垫持续低沉的大提琴，无明显起伏。
```

使用参考音频时，只在与可听层匹配的段落说明其复制或参考关系：环境声与音效属于 `overall_soundscape`，仅观众可听的配乐属于 `non_diegetic_music`。若同一音频同时提供两类内容，在各自段落描述对应关系：

```text
overall_soundscape: 从 <Audio 1> 复制的环境声层贯穿目标视频始终。
non_diegetic_music: <Audio 2> 被直接复用作完整的仅观众可闻配乐。
```

完整的对白与歌词只写在 `detailed_description` 的 `<d>` 内；不要在这两段重复。

## 7. 完整示例

<details>
<summary>显示完整示例</summary>

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的咖啡店环境，包含裸露砖墙、一张带花纹靠垫的橙色软包沙发、霓虹灯招牌，以及一张木质咖啡桌。
<Subject 2> 是 <Picture 2>、<Picture 3>、<Picture 4> 中那只毛茸茸的白色萨摩耶，有浓密白毛、尖耳朵、黑鼻子与卷曲的尾巴。
<Subject 3> 是 <Video 1> 中那位金发年轻女子，留长金发，穿浅粉色卷袖衬衫。
<Subject 4> 是 <Video 2> 中那位年轻男子，留短卷棕发，穿深灰色带抽绳连帽衫。
<Audio 1> 是 <Subject 3> (S1) 的音色参考，含一段英文口语声部。

summary:
[reference generation + audio reference] 目标视频展示 <Subject 3> 在 <Subject 1> 中吃饼干。<Subject 4> 带着 <Subject 2> 走进来，萨摩耶扑向饼干。这三镜的互动以 <Audio 1> 作为 <Subject 3> 的音色参考，并以一段罐头笑声收尾。
```
