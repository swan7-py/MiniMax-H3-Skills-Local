# Minimalist Product Ad Generator（本地版 · 逐步确认式）

> 本文件由原始 skill `minimalist-product-ad-generator` 改造为「本地版 · 逐步确认式」。
> **本地化改造总则 v2（纯提示词 · 逐步确认 · 交付物门）**
>
> **⏹ 门控硬规则（真停顿 · 已生效）**：本 skill 中每个 `⏸ 确认门` 与 `⏸ 交付物门` 均为**硬性停止点**，不是建议。固定执行顺序：① 仅输出当前步骤交付物（提示词 / 文本计划 / 分镜脚本等）；② **立即调用 AskUserQuestion 工具**，给三选项「✅ 确认，继续下一步」「✏️ 修改当前步」「⏸ 暂停 / 停止或换方向」；③ **等待用户回复**，本回复内**绝不可预生成任何后续步骤**（即使你觉得能一次写完）。任一 `⏸` 门不得跳过 / 合并，也不得仅用一句"请确认"文字代替——必须用 AskUserQuestion 真正阻塞。
> 1. **生图只给提示词，不调用任何生图工具**：anchor 图等生图步骤只输出文生图提示词；用户自行用任意工具生成图像，并把**图像文件路径或地址返回给我**。本 skill 不硬编码任何 ComfyUI 工作流路径。
> 2. **每一步都确认 + 交付物门（核心规则）**：每个步骤产出后我都会暂停，等你「确认 / 修改」。生图步骤必须等你**返回图像地址**后，才进入视频提示词步骤（视频提示词以 anchor 图为参考图）。
> 3. **视频提示词调用 `h3-prompt-writing` skill**：视频提示词均调用用户级 `h3-prompt-writing` skill（纯文本、无需 API）来写；以你返回的 anchor 图为参考图，按其 I2VA / Ref2VA 结构输出完整 H3 视频提示词，并附端口 / 顺序 / 时长 / 分辨率设置建议，由你在本地 H3 节点自行执行。 H3 特殊占位符 `<d>`/`</d>`、`<|lyrics_start|>`/`<|lyrics_end|>`、`<|caption_start|>`/`<|caption_end|>`、`<|cutoff|>` 及其固定 id 见 `h3-prompt-writing` 的「Special Tokens」节，写对白/歌词/字幕时严格照用。
> 4. **语音 / 音乐先询问（已升级为「音频模式门」）**：进入流程第一步（方向/简报锁定）时，必须先用 AskUserQuestion 问你**音频方案**，二选一：
>    - **A) 统一 H3 音频**：旁白 + 对白 + BGM 全部由 H3 原生音频驱动生成（最省事，音色/配乐与画面同步，无需外部文件）。
>    - **B) 分离生成**：旁白/对白只给提示词（你用任意 TTS 工具，推荐用「参考/音色克隆」模式保证跨镜头一致；不绑定 MOSS-TTS）、BGM 用 ACE-Step 1.5 本地生成（调用 `ace-step-1.5-prompt-writer` skill）、对白分别生成，后期合成。
>    - 记录你的选择，后续「视频提示词步骤」与「音频步骤」依此分支执行。
> 5. **旁白/对白一致性（分离模式必做）**：若选 B 且含旁白/对白，提醒你把【音色参考文件】（.wav/.mp3，代表目标音色）放到**当前项目文件夹（你运行本 skill 的工作目录）**，并在调用 TTS 时使用「参考模式 / 音色克隆」，确保多镜头音色统一；若你未提供该文件，先暂停请其提供，禁止无参考直接生成（否则各镜头音色漂移）。
> 6. **BGM 分离 -> 视频提示词只规划视觉（重要）**：若选 B，BGM 由 ACE-Step 1.5 单独生成，因此**调用 `h3-prompt-writing` 写视频提示词时不可规划 BGM/旁白/对白的音频出现**（如"音乐渐强""旁白响起""对话切入"等），只规划镜头/动作/画面；音频在后期合成。若选 A，视频提示词可正常包含音频驱动指令，无需单独生成音频。
> 7. **删除自动剪辑 / 拼接**：改为提供"剪辑思路"。
> 8. **规划 / 分镜 / 排版等文本方法论沿用原 skill**。
> 9. **删除"表情图"相关提示词**（原 skill 无独立表情图步骤，沿用即可）。

## Start Gate（沿用，必做）
一次确认：①产品图/素材；②单变体或多变体；③时长 5/10/15s（默认 10s）；④画幅 16:9/9:16/1:1/4:3/3:4/参考；⑤Apple 模板（白科技/暗边光/品牌色场/轻生活）；⑥文案（你提供 or Agent 生成 Apple 风英文）；⑦视频模型策略（默认 MiniMax-H3，显示即可，不在此问你）。
- ⏸ **确认门**：用文字确认替代 choice card，呈现后暂停等你确认。

## STEP 1：资产检查与产品事实
同原 skill：品类/主体位置/画质/主色/可展示结构/真实外观特征；不可用则给重拍建议。

## STEP 2：确认制作简报
同原 skill：材质/主变体/画幅/时长/Apple 模板/单多变体/文案模式。
- ⏸ **确认门**：简报呈现后暂停，等你确认。

## STEP 3：产品叙事脊
同原 skill：Product Launch（默认）/ Feature Touch / Color Family，三选一确认。
- ⏸ **确认门**：叙事脊呈现后暂停，等你选向确认。

## STEP 4：运动语言
同原 skill：真实产品/视觉元素驱动转场；每 beat 一主动作；强弱/安静时刻；保留净空；避假科技装饰/镜面白舞台/空开场。

## STEP 5：Apple 风英文文案
同原 skill：3–5 词、非口号、按产品新写；你已有文案优先；中文本地化为英文。

## STEP 6：三张独立 anchor 图（只给提示词 + 交付物门）
同原 skill 角色（Photo1 hero / Photo2 材质细节 / Photo3 文案构图），三张独立不拼版。
**调用用户级 `image-prompt-writer-local` skill** 生成富结构提示词：传入 场景类型=产品静物（Photo1 hero/Photo2 材质/Photo3 文案构图）、风格上下文=极简/Apple 风、主体与要求=产品本体+三张变体定义（Photo3 文案构图按原排版规则：单行、SF Pro Display Semibold、前半黑/白后半产品色）。它返回「通用风格锚 + 三张 anchor 图四段式详描」，你原样呈现。
**本步骤产出**：每张 anchor 图的**文生图提示词**（来自上一步 skill 输出，Photo3 文案构图按原排版规则：单行、SF Pro Display Semibold、前半黑/白后半产品色）。
- ⏸ **交付物门（必过）**：提示词给你后暂停。请你生成三张 anchor 图并**返回图像地址**（作为视频参考图1/2/3）。收到后才进入 STEP 7/8。
> 本地化：**删除"表情图"相关提示词**。

## STEP 7：精确节拍与文字分镜表
同原 skill：列 `时间范围/镜头/目的/视觉主导/视觉·相机运动/变体状态/文案/文字色/文字效/转场连续/节奏意图`；单句单行英文文案；最终 beat 稳定单帧产品+单行文案收尾。
- ⏸ **确认门**：分镜表呈现后暂停，等你确认。

## STEP 8：视频提示词（调用 h3-prompt-writing + 设置建议 + 交付物门）
**不再由本 skill 直接写 H3 提示词，改为调用 `h3-prompt-writing` skill**：
- 输入：STEP6 返回的三张 anchor 图地址（hero / 材质 / 文案构图）+ STEP7 节拍分镜文本。
- **调用用户级 `h3-prompt-writing` skill**（纯文本、无需 API），按其 I2VA / Ref2VA 结构，输出完整 H3 视频提示词（含三张 anchor 角色、完整节拍表逐 beat 改写、逐条文案与色/时窗/单行行为）；并附设置建议：
  - 参考图1/2/3 = STEP6 三张 anchor 图 → 依次接入 H3 节点「图像参考 / image reference」端口（按节点端口数接入；若单端口则轮流或取主变体图）
  - 音频（依总则「音频模式门」分支）：模式=统一H3 时，提示词内写 Apple 科技 BGM 方向（H3 原生音频开）；模式=分离 时，本视频提示词**仅规划视觉**，不写 BGM 方向，音乐由 ACE-Step 1.5 生成后接「音频输入」端口。
  - 时长 = STEP1 确认值（默认 10s）；分辨率 = STEP1 画幅对应值；其余你自定
  - 模型标注 MiniMax-H3；本地用 Wan/Animate2 亦可（首帧接 anchor）
- **本步骤产出**：完整 H3 视频提示词 + 端口/顺序/时长/分辨率设置建议。
- ⏸ **交付物门（可选）**：你确认提示词后自行在 H3 执行，返回成片地址（可选）。

## STEP 9：BGM（先问云端）
> ⚠️ 音频模式门：仅模式=分离 时执行本 STEP 的 BGM 单独生成（调用 `ace-step-1.5-prompt-writer`）；模式=统一H3 时跳过。
> ⚠️ 音频模式门：仅模式=分离 时执行本 STEP 的 BGM 单独生成（调用 `ace-step-1.5-prompt-writer`）；模式=统一H3 时跳过。
涉及 BGM 时先问你「用云端生成 or 只给提示词」。若只给提示词，输出 BGM 风格提示词（约 100 BPM、科技感、块状和弦、pluck+airy noise、kick+sub、木质打击、突断留 pluck 尾音）。若只给提示词，优先**调用用户级 `ace-step-1.5-prompt-writer` skill** 改写成 ACE-Step 1.5 提示词（Caption/Lyrics/Metadata），再交你本地或云端生成。

## STEP 10：剪辑思路（替代自动剪辑）
- 原视频为一条连续全幅产品片；多 clip 时按 beat 顺序硬切拼接。
- 音乐分析：找 8–12s 连续有声且能量适合的段；剪连续音乐段替换视频音轨、静音原音轨；响度克制。
- 工具建议：ffmpeg 或本地剪辑软件；不做长 fade，必要时 0.1–0.3s 尾淡。
- 交付核对：画幅/时长/语言匹配；产品主变体/变体时序匹配；文案单行可读无符号；终帧稳定产品+文案；音乐不过响不过弱。

## 排版硬约束（沿用，写入 H3 提示词）
任意时刻仅一条单行英文文案；禁双行/标题+副标/多文字块；恰两色（黑或白 + 产品主色）；同一行内前半淡入/后半稍后淡入且前半微移让位；不静态不拆上下行；Apple 风白科技前半黑/深灰、暗边光前半可白、后半恒产品色。
