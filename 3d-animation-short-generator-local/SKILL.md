# 3D Animation Short Generator（本地版 · 逐步确认式）

> 本文件由原始 skill `3d-animation-short-generator` 改造为「本地版 · 逐步确认式」。
> **本地化改造总则 v2（纯提示词 · 逐步确认 · 交付物门）**
>
> **⏹ 门控硬规则（真停顿 · 已生效）**：本 skill 中每个 `⏸ 确认门` 与 `⏸ 交付物门` 均为**硬性停止点**，不是建议。固定执行顺序：① 仅输出当前步骤交付物（提示词 / 文本计划 / 分镜脚本等）；② **立即调用 AskUserQuestion 工具**，给三选项「✅ 确认，继续下一步」「✏️ 修改当前步」「⏸ 暂停 / 停止或换方向」；③ **等待用户回复**，本回复内**绝不可预生成任何后续步骤**（即使你觉得能一次写完）。任一 `⏸` 门不得跳过 / 合并，也不得仅用一句"请确认"文字代替——必须用 AskUserQuestion 真正阻塞。
> 1. **生图只给提示词，不调用任何生图工具**：每个生图步骤只输出文生图提示词；用户自行用任意工具（本地 ComfyUI / 在线 / 其他）生成图像，并把**生成的图像文件路径或地址返回给我**。本 skill 不硬编码任何 ComfyUI 工作流路径。
> 2. **每一步都确认 + 交付物门（核心规则）**：每个步骤产出后我都会暂停，等你「确认 / 修改」。凡涉及生成资产的步骤（生图 / 生视频 / 生音频），必须等你**返回对应交付物（图像地址 / 视频地址 / 音频地址）**后，才进入下一步。典型链路：出角色卡生图提示词 → 等你返回图像地址 → 再以其为参考图出视频提示词（视频提示词与图像强相关，绝不提前批量给全）。
> 3. **视频提示词调用 `h3-prompt-writing` skill**：所有视频生成提示词，均调用用户级 `h3-prompt-writing` skill（纯文本、无需 API）来写；以你返回的图像为参考图，按其 I2VA / Ref2VA / T2VA 结构输出完整 H3 视频提示词，并附端口 / 顺序 / 时长 / 分辨率设置建议，由你在本地 H3 节点自行执行。 H3 特殊占位符 `<d>`/`</d>`、`<|lyrics_start|>`/`<|lyrics_end|>`、`<|caption_start|>`/`<|caption_end|>`、`<|cutoff|>` 及其固定 id 见 `h3-prompt-writing` 的「Special Tokens」节，写对白/歌词/字幕时严格照用。
> 4. **语音 / 音乐先询问（已升级为「音频模式门」）**：进入流程第一步（方向/简报锁定）时，必须先用 AskUserQuestion 问你**音频方案**，二选一：
>    - **A) 统一 H3 音频**：旁白 + 对白 + BGM 全部由 H3 原生音频驱动生成（最省事，音色/配乐与画面同步，无需外部文件）。
>    - **B) 分离生成**：旁白/对白只给提示词（你用任意 TTS 工具，推荐用「参考/音色克隆」模式保证跨镜头一致；不绑定 MOSS-TTS）、BGM 用 ACE-Step 1.5 本地生成（调用 `ace-step-1.5-prompt-writer` skill）、对白分别生成，后期合成。
>    - 记录你的选择，后续「视频提示词步骤」与「音频步骤」依此分支执行。
> 5. **旁白/对白一致性（分离模式必做）**：若选 B 且含旁白/对白，提醒你把【音色参考文件】（.wav/.mp3，代表目标音色）放到**当前项目文件夹（你运行本 skill 的工作目录）**，并在调用 TTS 时使用「参考模式 / 音色克隆」，确保多镜头音色统一；若你未提供该文件，先暂停请其提供，禁止无参考直接生成（否则各镜头音色漂移）。
> 6. **BGM 分离 -> 视频提示词只规划视觉（重要）**：若选 B，BGM 由 ACE-Step 1.5 单独生成，因此**调用 `h3-prompt-writing` 写视频提示词时不可规划 BGM/旁白/对白的音频出现**（如"音乐渐强""旁白响起""对话切入"等），只规划镜头/动作/画面；音频在后期合成。若选 A，视频提示词可正常包含音频驱动指令，无需单独生成音频。
> 7. **删除自动剪辑 / 拼接**：不调用剪辑工具；改为提供"剪辑思路"（ffmpeg 或本地剪辑软件）。
> 8. **规划 / 分镜 / 排版等文本方法论沿用原 skill，原样保留**。
> 9. **删除全部"表情图"相关提示词**（本地难做参考表情，省略）。

## 适用范围
- 用：完整叙事动画工作流（强角色一致性、场景连续、镜头/表演/音频可控）。
- 不用：单图、简单剪辑、写实实拍、单条独立 clip。

## 全局视觉风格锁（沿用）
除非用户另选：Pixar 风 3D 卡通渲染、C4D+Octane 质感、夸张几何简化 + 材质细节、2.5–3 头身 Q 版比例、雕塑感发毛、暖色次表面散射皮肤、夸张迪士尼式表演、高能量弹性肢体动画。
禁用：写实实拍、平涂 2D 动漫、塑料玩具皮肤、僵硬摆姿。

## STEP 0：Intake 与画布规划
同原 skill：采集一句话创意、交付物类型、时长、画幅、视觉基调、是否对白/旁白。用文字确认替代 choice card：
- 画幅：16:9 横 / 9:16 竖 / 1:1 / 4:5 / 自定义
- 总时长：30–60s（推荐）/ 15–30s / 60–90s / 90–180s / 自定义
- ⏸ **确认门**：呈现上述采集项后暂停，等你「继续 / 改 / 停」再往下。

## STEP 1：项目简报
同原 skill，写入文本节点 `项目简报`。
- ⏸ **确认门**：简报呈现后暂停，等你确认或补充。

## STEP 2：故事大纲与门控
同原 skill（8 拍因果脊 + 情感锚）。
- ⏸ **确认门**：大纲呈现后暂停，门控检查通过、你确认后再往下。

## STEP 3：角色卡（生图提示词 + 交付物门）
同原 skill 角色顺序（主角→对照/压力角色→可选配角）。每张角色卡建议含：
- 角色名（中/英）、角色定位、主 3/4 视图 + 正/侧/背/3-4 视图（**四视图，原三视图已改**）
- 材质/服装/道具细节、身份锁定注记（年龄/体型/发型/配色/签名道具/不可变特征）
- **删除表情图相关提示词**（本地参考表情难度过大，省略）。

**调用用户级 `image-prompt-writer-local` skill** 生成富结构提示词：传入 场景类型=人像/角色四视图、风格上下文=本片统一画风、主体与要求=各角色（名/定位/四视图/材质服装/不可变特征，已删表情图）。它返回「通用风格锚 + 每张角色卡四段式详描」，你原样呈现。
**本步骤产出**：每张角色卡的**文生图提示词**（来自上一步 skill 输出，你自行保存/使用）。
- ⏸ **交付物门（必过）**：我把角色卡提示词给你后暂停。请你：①确认/修改提示词；②用任意生图工具生成角色图像；③**返回生成的图像文件路径或地址**（作为后续视频的参考图1）。收到图像地址后，我才进入 STEP 4。

## STEP 4：场景卡（生图提示词 + 交付物门）
同原 skill：仅环境、不含人物。建议场景参考图：主环境、光照态、情绪子空间、连续性地标、重要道具。
**调用用户级 `image-prompt-writer-local` skill** 生成富结构提示词：传入 场景类型=风景/场景、风格上下文=本片统一画风、主体与要求=各场景（主环境/光照态/情绪子空间/连续性地标/重要道具）。它返回「通用风格锚 + 每张场景卡四段式详描」，你原样呈现。
**本步骤产出**：每张场景卡的**文生图提示词**（来自上一步 skill 输出）。
- ⏸ **交付物门（必过）**：提示词给你后暂停。请你生成场景图像并**返回图像地址**（作为参考图2）。收到后才进入 STEP 5。

## STEP 5：六列标准镜头表
同原 skill，强制六列：`Shot ID & Duration` / `Continuity Handoff` / `Reference Anchors` / `Hook Type` / `Shot Description（逐秒指令）` / `Audio & Dialogue Track`。运行 5.5 自检门。
- ⏸ **确认门**：镜头表呈现后暂停，等你确认。

## STEP 6：文字分镜文档（默认）+ 铅笔分镜（可选）
同原 skill：默认单一文字分镜文档（每镜一节）；铅笔分镜仅作可选可视化。
- ⏸ **确认门**：分镜呈现后暂停，等你确认。

## STEP 7：单镜头视频提示词（调用 h3-prompt-writing + 交付物门）
**不再由本 skill 直接写 H3 提示词，改为调用 `h3-prompt-writing` skill**：
- 输入：STEP 3 返回的角色图像地址（参考图1）+ STEP 4 返回的场景图像地址（参考图2）+ STEP 5/6 的镜头/分镜文本。
- **调用用户级 `h3-prompt-writing` skill**（纯文本、无需 API），按其 I2VA / Ref2VA 结构，逐镜头输出完整 H3 视频生成提示词；并附设置建议：
  - 参考图1（角色）→ 接入 H3 节点「角色参考 / character reference」图像端口
  - 参考图2（场景）→ 接入「场景参考 / scene reference」图像端口
  - 音频（依总则「音频模式门」分支）：模式=统一H3 时，旁白/对白/BGM 由 H3 原生生成并接「音频输入 / audio」端口（纯 T2VA 不接）；模式=分离 时，本视频提示词**仅规划视觉**（不写 BGM/旁白/对白音频指令），音频后期合成。
  - 时长 = 由简报决定（单镜按需分段）；分辨率 = 由简报画幅决定（16:9→1920×1080 等）；其余你按节点默认或自行调整
  - 模型标注 MiniMax-H3；本地用 Wan/Animate2 亦可（相应调整端口/首帧接入）
- **本步骤产出**：完整 H3 视频提示词 + 端口/顺序/时长/分辨率设置建议。
- ⏸ **交付物门（可选）**：你确认提示词后，自行在本地 H3 节点执行生成视频；**返回成片地址（可选）**。未返回也可直接继续（如无需拼接）。

## STEP 8：整片组装与 BGM（先问云端 + 剪辑思路）
> ⚠️ 音频模式门：仅模式=分离 时执行本 STEP 的 BGM 单独生成（调用 `ace-step-1.5-prompt-writer`）；模式=统一H3 时跳过，BGM 由 H3 原生生成。
> ⚠️ 音频模式门：仅模式=分离 时执行本 STEP 的 BGM 单独生成（调用 `ace-step-1.5-prompt-writer`）；模式=统一H3 时跳过，BGM 由 H3 原生生成。
- **BGM（先问云端）**：涉及 BGM 时，先问你「用云端生成 or 只给提示词」。若只给提示词，输出 BGM 风格提示词（约 100 BPM、科技感、块状和弦、pluck + airy noise、kick+sub、木质打击、突断留 pluck 尾音）。若只给提示词，优先**调用用户级 `ace-step-1.5-prompt-writer` skill** 把你的一句话音乐描述（+ 可选带 `[Verse]`/`[Chorus]` 等标签的歌词）改写成 ACE-Step 1.5 提示词（Caption/Lyrics/Metadata），再交你本地或云端生成。
- **剪辑思路（替代自动剪辑）**：
  - 严格按镜头表顺序拼接；仅用最新批准资产。
  - 对白/反应/重要 SFX 处压低 BGM。
  - 不额外加字幕/文字（除非你要）。
  - 成片不得残留分镜痕迹（标签/箭头/计时标记/面板边框）。
  - 工具建议：ffmpeg 或本地剪辑软件硬切拼接；多镜头可用首尾帧衔接保证连续。

## 边界
同原 skill：不用于单图、简单剪辑、单 clip、logo、纯提示词咨询。
