# 04 · 特殊与复合运镜（D 族）

---

## D1 希区柯克变焦（dolly zoom）

**镜头句**
```
[Shot 1] 景别为中景、取景 <Subject 1> 腰部以上。
<Subject 1> 突然抬头看向镜头，同时镜头进行 dolly zoom 推进变焦。
```

- **实测**：🟡 **三版隔离试跑全部退化成普通推镜**（脸高末/首 1.59 / 1.50 / 2.05）。补"本质句"无效（差 6%，噪声内）
- **用户裁定**：**以 v1（`zm_ess`，即上句）为最终生成版**——指标判"普通推镜"被目视推翻（v1 的背景位移最猛 `s_global`=0.60、脱钩 0.90 为三版最远）
- **LoRA**：`dolly_zoom_minimaxh3_v1`（触发词 `dolly_zm`）——⚠️ **在 Ref2VA 下没做出反变焦**，与 DSL「最不可靠镜头」的警告一致
- **坑**：① 判据是 `s_face≈1.0 且 s_global≠1.0 且脱钩≥0.10`，但**脸高代理会被"抬头"这类姿态变化污染**，不能作否决依据，必须配接触印相**目视**；② 不要用指标强判它

## D2 急推变焦（crash zoom）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
镜头以大幅、快速向 <Subject 1> 猛推，这是一次突然的急推变焦；
机位位置全程固定在同一点，画面变化全部来自镜头变焦。
```

- **实测**：🟡 末帧面部特写；"急"的程度（峰值 / 中位）：**③ Crash Zoom 6.44 ＞ ① 原生 5.12 ＞ ② Jojocodex 2.44**
- **LoRA**：✅ **Crash Zoom 真有效**——Jojocodex 反而把突变**抹平**了（2.44）
- **坑**：急推的"急"是**突变**不是"快"；用峰值 / 中位量衡量，别用平均速度

## D3 甩镜

**镜头句**
```
[Shot 1] 画面起初落在外廊边上的一丛花上——花朵位于画面中央、清晰可见，随风轻摆。
镜头以极快的甩镜向右甩过、落到 <Subject 1> 身上，落到他身上时的取景为中景、腰部以上；
此后镜头一直停留在他身上直到片子结束。
```

- **实测**：❌ 初版（主体 → 甩到太阳）**不成功**；✅ **反过来（一丛花 → 甩到主体）成功**
- **坑（两条）**：
  1. **甩镜必须有落点，且落点要写死**——落到什么、落到之后的取景是什么，都要写；
  2. **起手物写在最前面**（书写顺序铁律），且 DSL 的 `/WHIPPAN` 默认"先取景主体"，与我们的设计**相反**——按本库写

## D4 荷兰角

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
地平线向右倾斜，形成荷兰角，这一倾斜贯穿全片；
画面里近景的柱身随之明显倾斜。
```

- **实测**：✅ **③ Dutch Angle Slider 确有倾角**（中帧近景柱身明显倾斜）；①原生 ②Jojocodex **均无倾角**
- **LoRA**：⭐ **必须挂 `H3_Dutch_Angle_Slider_v1`**——单句提示词对 Ref2VA **不足以驱动倾角**
- **权重（2026-10-09 修正）**：**权重即倾角，1 ≈ 20°**；D4 定稿 **strength = 2.0**
  （⚠️ 旧版资料写"1.0 ≈ 1°、要 10–20"，那是错的）
- **坑**：**倾角测不出来**——Hough 竖直边会被屋檐、竹枝等场景斜线污染。**只能目视判**

## D5 移焦（rack focus）

**镜头句（必须把两个对象写死）**
```
景别为中景、取景 <Subject 1> 腰部以上；
焦点随后从前景的 <Subject 1> 移至背景的月洞门，前景逐渐变虚、背景逐渐变实；
取景与机位保持不变。
```

- **实测**：✅ 成立**但属运气**——初版提示词里**没有移焦对象**，画面恰好出现"廊道向前延伸 + 尽头月洞门"才成立，另一条件因此失败
- **坑**：**移焦必须写死"从 A 到 B"两个对象**（深度不同的两个平面），不写就靠运气

## D6 揭示运镜（遮挡 → 横移 → 移焦）

**镜头句**
```
[Shot 1] 画面起初被一根朱红木柱的柱身挡住——柱身占据画面左侧、清晰锐利，柱子后方的庭院与外廊是虚的。
近景处有一个元素位于机位与 <Subject 1> 之间；
机位以慢速向左横移，末帧 <Subject 1> 位于画面右侧；
机位沿横向侧移，镜头朝向全程锁定在同一方向。
```

- **实测**：🟡 起手命中（柱挡 + 主体虚化）；**末帧主体落在左侧**，与"末帧落位句"不符（同 B3 的不稳定）
- **坑（两条）**：
  1. **起手必须先写遮挡物**（改书写顺序后起手只余柱子，主体尚未出现）——这条是本镜能成立的关键；
  2. 末帧落位句不稳定，换种子可能反向，先看首片

## D7 推 + 仰复合

**镜头句**
```
起手景别为中景、取景 <Subject 1> 腰部以上；
机位以慢速前移推近，推近贯穿全片持续稳定，末帧为 <Subject 1> 胸口以上的中近景；
焦距全程锁定在同一档位；
同时机位以慢速向上仰摇。
```

- **实测**：✅ 成立
- **坑**：复合运动最多"进入 / 主运动 / 落稳"三段，或两个**物理连续**的运动（推 + 仰是连续的）；不要堆三个以上互不相干的运动

---

## 本族通用纪律

1. **特殊运镜里，LoRA 的作用大于措辞**：荷兰角必须靠 LoRA（D4）、急推靠 Crash Zoom（D2）、整圈靠 360 类；
2. **起手物写最前面**（D3 / D6 都是靠这条救回来的）；
3. **"急 / 猛"这类词要配具体落点或程度对象**，否则模型自由发挥；
4. 复合运动**先选目的再选手法**，一个主运动 + 最多一个物理连续的第二运动。
