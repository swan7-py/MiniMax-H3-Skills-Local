# 06 · 装置与风格运镜（F 族）

---

## F1 手持（轻） / F2 手持（强）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位轻微手持晃动。            # F2：机位强烈手持晃动
```

- **实测**：🟡 成立
- **坑**：⭐ **"抖动"量化不了**——逐帧差变异系数、相位相关位移的 jerk 在 480P 里会被场景变化与主体运动污染（累计位移高达 2000–20000 px）。**只能目视判**
- **待验证假设**：稳定镜头里写"不晃动"**可能反而诱发抖动**（提到 X 会提高 X 出现的概率）。所以稳定镜头要写正向句"画面全程平稳顺滑"

## F3 斯坦尼康

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位平滑漂浮，画面全程平稳顺滑。
```

- **实测**：✅ 平滑跟随
- **LoRA**：`MMH3-LOCKSTAB-MORE`（触发词 `lockstab`）
- **坑**：**绝不出现装置名**（斯坦尼康 / 云台 / 无人机 / 滑轨）——DSL 实测「命名的机身装置会被画进画面里」。**描述效果，不描述器材**

## F4 跟拍（身侧） / F5 追逐跟拍（身后）

**镜头句（F4）**
```
[Shot 1] <Subject 1> 沿廊道向画面右侧走着，单手微微抬起正在安静的思考。
景别为中景、取景 <Subject 1> 腰部以上；
机位以 <Subject 1> 的步伐沿他身侧同行、朝画面右侧移动；
机位全程停在他身侧，<Subject 1> 的整个上半身留在画面内；
```

**镜头句（F5）**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位以快速在他身后跟随、进行跟拍；
<Subject 1> 的整个上半身全程留在画面内。
```

- **实测**：✅ 两者都成立
- **LoRA**：`MMH3-LOCKSTAB-MORE`（`lockstab`）
- **坑**：**"整个上半身全程留在画面内"这句要写**——跟拍类不写就会丢主体

## F6 无人机航拍 / F7 无人机拉升

**镜头句（F6）**
```
[Shot 1] 画面起初是高空俯瞰下的整座庭院与外廊：<Subject 1> 站在那条长长的廊道中，从上往下看只是一个小小的身影；
景别为极远景，<Subject 1> 在广阔的空间中显得很小；
机位在空中平稳移动；
机位在空中向前飞行、地面自下方掠过。
```

**镜头句（F7）**
```
景别为全身景、取景 <Subject 1> 从头顶到脚底；
机位垂直上升；
它一直升到 <Subject 1> 远远地变得很小、整个场所在他周围展开。
```

- **实测**：✅ F6 起手即高空全景、主体极小；F7 成立
- **LoRA**：`dr0nesh0t_aerial_flyover_000000500`（无触发词）
- **用户裁定**：**F6 / F7 推荐原生**（成片保留 1080P drone 版）
- **坑**：起手物是**高空全景**，必须先写环境再写主体（书写顺序铁律）

## F8 穿越（月洞门） / F9 遮挡穿越（枝叶）

**镜头句（F8）**
```
[Shot 1] 画面起初是廊道尽头的月洞门——圆形的门洞把画面框住，门洞里透出门后明亮的庭院与竹丛。
机位向前推进；
```

**镜头句（F9）**
```
[Shot 1] 画面起初被前景的一丛花与枝叶挡住——枝叶贴着镜头、清晰可辨，后面的外廊与庭院是虚的。
机位以慢速向前推进；
镜头穿过枝叶进入廊道；
```

- **实测**：✅ 两者都成立
- **坑（两条）**：
  1. **起手物写在最前面**（门洞 / 枝叶），DSL 只有 `FLYTHROUGH` 一个原语，**两者靠速度 + 起手物区分**；
  2. 穿越要写"穿过之后进入什么空间"

## F10 视差运镜（近景前景 + 横移）

**镜头句**
```
[Shot 1] 这里是那座中国古典庭院外廊与克制赛博朋克科技相融的白天实景，长长的外廊从左向右横贯整个画面。
画面最左侧的近景处立着一根粗壮的朱红木柱：柱身漆面斑驳、木纹与裂纹清晰锐利，它挡在机位与 <Subject 1> 之间；
柱子右侧的廊道上，<Subject 1> 站在石栏杆前侧身面向镜头；
画面中自始至终只有 <Subject 1> 这一位人物。
景别为中景、取景 <Subject 1> 腰部以上；
位于近景的是那一根朱红木柱的柱身，它挡在机位与 <Subject 1> 之间；
机位以慢速向左横移，末帧 <Subject 1> 位于画面右侧；
机位沿横向侧移，镜头朝向全程锁定在同一方向。
随着机位持续向左横移，近景那根柱身自画面左缘缓缓移出，远景的柱列、栏杆与庭院景物陆续被它遮住又重新露出，
近景与远景之间被拉开明显的前后错位；
```

- **实测**：✅ 起手近景柱身，横移时近远景相对位移成立
- **坑（本组最重要的三条）**：
  1. ⭐ **双主体陷阱**：同一提示词 + 同种子，**4:3 出双脸、1.8:1 不出**——模型会"复制一个人"来补位。**防复制双保险句**：`画面中自始至终只有 <Subject 1> 这一位人物`；强调版 `画面里出现的每一处身体、每一段衣袖与每一缕头发都只属于这一位人物`；
  2. **环境修补句会变成构图指令**：`被这根柱身遮住的是廊道向纵深延伸的柱列与地砖` 本意只是交代遮挡物后面是什么，却被读成"要纵深构图" → 横移失去横向空间。→ **横移镜要给走向句**（"长长的外廊从左向右横贯整个画面"），**规避"纵深"字眼**（前后层次改说"前后错位"）；
  3. **画幅是隐藏变量**：跨画幅复用提示词前先预期这个风险（详见 `09-reality-and-pitfalls.md`）

## 本族通用纪律

1. **绝不出现器材名**（斯坦尼康 / 云台 / 无人机 / 滑轨 / 摇臂）——描述效果；
2. **稳定类写正向句**（"画面全程平稳顺滑"），不写"没有晃动"；
3. **跟拍类要写"主体全程留在画面内"**；
4. **穿越类起手物写最前面**；**横移类给横向空间、规避纵深**；
5. **抖动 / 稳定只能目视判**，别硬凑指标。
