# 03 · 环绕 · 螺旋 · 翻滚 · 子弹时间（C 族）

> 本族是**最容易"看着对、其实错"**的一族：闭环与否只看首末灰度相关（≥0.85 才算闭环），别用"感觉转过去了"判断。
> 整圈类的写法已按 2026-10-09 校准：**圈数 + 起止时刻，两者都要写**。

---

## C1 半环绕 180°

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位以慢速沿弧线绕 <Subject 1> 向镜头右侧移动，弧线约 180 度；
机位始终把 <Subject 1> 保持在画面中央。
```

- **实测**：✅ 成立（末帧正背面）
- **LoRA**：可挂 360 类（`minimax_h3_flf2v_lora_v1`，触发词＝整段 caption）作对照，半环绕原生即可
- **判据**：半环绕的落点是**正背面**，不是"回到起点"——别用闭环阈值判它

## C2 全环绕 360°

**镜头句（校准版）**
```
景别为中景、取景 <Subject 1> 腰部以上；
At 00:00.500 机位开始沿弧线绕 <Subject 1> 转满一整圈；
At 00:09.500 末帧回到正面收住；
<Subject 1> 保持这一站姿与朝向、留在原地。
```

- **实测**：❌ 原生与 Jojocodex 均未达闭环阈值（0.647 / 0.642 / 0.670）；**③b（pablodawson 360-Orbit）里程碑版 0.931** → **用户裁定：C2 采用 ③b 版**
- **LoRA**：⭐ **必须挂 360 类 LoRA**，不挂几乎不闭环
- **坑（三条）**：
  1. **速度词会让圈数失效**——写"快速"时镜头冲过正面继续转第二 / 第三圈，"整整一圈"被吃掉。→ 速度交给 `At` 时刻，不交给速度词；
  2. **闭环靠收束句「末了回到正面」**，不靠秒数；
  3. **只给圈数不给时长 → 转多圈或中途停；只给时长不给圈数 → 不转或转不完**。

## C3 子弹时间（3s · 整圈 + 时间凝滞）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
时间在起手后立即凝滞，<Subject 1> 冻结在起手那一刻的位置与形态上；
At 00:00.200 机位开始沿弧线绕 <Subject 1> 转满一整圈；
At 00:02.800 末帧回到正面收住；
```

- **实测**：✅ **③b 0.927（唯一达标）**；原生与 Jojocodex ≈ 0
- **LoRA**：⭐ 必须挂 360 类
- **时长**：本镜为 3s（73 帧），是 29 条 1080P 批次里唯一的例外
- **坑**：时间凝滞要先于运镜句写出；发丝、衣摆、尘埃**保持静止**才能读成"时间停了"——不要写"随风飘动"

## C4 螺旋环绕（整圈 + 持续升高）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
At 00:00.500 机位开始沿弧线绕 <Subject 1> 转满一整圈，末帧回到正面；
同时机位以慢速垂直升高。
```

- **实测**：🟡 0.240 / 0.646（未达闭环）；**用户裁定：C4 采用原生版**
- **坑**：两个运动叠加时，整圈的收束句依然要写；升高速度用"慢速"由 `At` 时刻配速更稳

## C5 翻滚（绕光轴自转 360°）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位以慢速顺时针绕自身光轴翻滚，翻滚约 360 度。
```

- **实测**：❌ v4 补了顺时针仍未闭环（−0.085 / 0.229）；**`_v2` 版曾达 0.976 / 0.972** → **用户裁定：C5 采用原生 `_v2` 版**
- **坑（两条）**：
  1. **方向必写**（顺时针 / 逆时针）——不写则由模型自选，不可复现；
  2. **中途必须真的倒置**：翻滚的判据是**约 50% 处画面完全倒置**，只"转了一圈但中途没倒"不算翻滚；
  3. 本镜对**提示词细节敏感**（`_v2` 与 v4 差距 0.97 vs −0.08），先看首片再改词，换种子优先于改词。

## C6 子弹时间 · 中段（3–6s 环绕，前后静止）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
前 3 秒机位保持静止；
约在第 3 秒处，机位开始沿弧线绕 <Subject 1> 转满一整圈、末帧回到正面，<Subject 1> 保持这一站姿与朝向、留在原地；
约在第 6 秒处，机位保持静止。
```

- **实测**：🟡 ③b 0.855 达标；**但"前 3 秒静止"未被遵守**（实测 0.67–1.71s 就开始环绕，提前 1.3–2.3 秒）→ **用户裁定：C6 采用原生 v4 版**
- **坑**：**分段时刻会漂移约 ±1 秒**（这是 C 族最典型的失败）。设计分段时间轴时按模型节奏反推，别把秒表当合同

---

## 本族通用纪律

1. **整圈＝圈数 + 起止时刻，缺一不可**（见 `00-core-discipline.md` §六）；
2. **整圈几乎必须挂 360 类 LoRA**（C2 / C3 / G4 三条独立验证：不挂 0.094 / −0.035 / 0.65 上下，挂了 0.927–0.950）；
3. **闭环判据＝首末灰度相关 ≥0.85**（非整圈类不适用）；
4. 提示词对细节敏感 → **先看首片，换种子优先于改词**（DSL 官方也记了 seed sensitivity HIGH）。
