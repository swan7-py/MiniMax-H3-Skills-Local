# 09 · Ref2VA 的现实边界与已知陷阱

> 这一份回答的是"**别指望什么**"——写运镜提示词前先看它，能省掉一半返工。

---

## 一、指标可用性：能测什么、不能测什么

### ✅ 可用（与相机无关的开关量式判断）

| 指标 | 用途 | 判据 |
|---|---|---|
| 起手前 5 帧差 | 检测首帧 / 锚图造成的**跳帧** | 正常 0.002–0.09；跳帧会明显突出 |
| Δ(t)＝各帧与首帧的平均绝对差 | **走得远不远**、什么时候在动 | 取阈值后的**运动区间**（何时开始 / 结束） |
| 首末灰度相关 | **整圈 / 翻滚类是否回到起点** | ≥0.85 视为闭环；非整圈类无意义 |
| 最大单帧跳变的位置 | 检测**硬切**（正反打） | G2 实测在第 85 帧（3.54s） |
| 音频 RMS 包络（40ms 窗） | **有没有人声** | 有对白组峰值中位 0.4845 vs 无对白组 0.1032，**差 4.69 倍** |
| SCRFD 逐帧数脸 | 查**重复主体 / 双主体** | 注意误检，见 §三 |

### ❌ 不可用（三次踩坑，别再硬凑）

| 想测什么 | 试过什么 | 为什么不行 |
|---|---|---|
| 荷兰角倾角 | Hough 竖直边中位数 / 方向直方图 | 场景里的屋檐、竹枝等斜线污染，峰值在水平与斜向之间跳 |
| 推镜头的"推" | 以缩放拟合的 zoom 代理 | 真推拉带透视与视差变化，corr 只有 0.24–0.38 |
| 手持抖动 | 逐帧差变异系数 / 相位相关位移的 jerk | 480P 里场景在变、主体在动，全局统计量混入太多非相机因素 |
| "幅度好坏" | 峰值 Δ | 会被主体漂移与画面崩坏一起抬高——**Δ 大 ≠ 运镜好** |

→ **结论**：相机"抖动 / 倾角 / 幅度精度"这类量**只能目视判**；机器只负责跳帧 / 运动区间 / 闭环 / 硬切位置 / 有无对白。

## 二、起手景别：Ref2VA 本身不受控

- 官方矩阵：「中景及更近」取景 **0/51**，起手命中 6/48，**可测偏差 40/40 全部是"偏宽"**；
- 三条"锁半身"花招全部无效：crop-line 句 ❌、腰部以上裁切参考图 ❌、构图锚图 ❌；
- 唯一能做：环境改描述式（主体放大 2.4–3×，**仍非腰部以上**）；
- **正解（DSL 官方）**：**取景必须精确 → 用 I2VA 真实首帧**，首帧决定取景 / 高度 / 角度，文字只管运动；
- **种子敏感度 HIGH**：先看首片，**换种子优先于改词**（`try another seed before rewording`）。

## 三、双主体陷阱与画幅这个隐藏变量（F10 案例）

**五版对照（SCRFD 逐帧数脸）**：

| 版本 | 结果 |
|---|---|
| 480P 原文 + 种子 20261005 | 0 双脸 |
| 1080P 4:3 **照搬 480P 原文 + 同种子** | **8 帧双脸** |
| 1080P v2 横向版 | 0 双脸 |
| 16:9 复验 | 真双脸 0 |

→ **双主体是「提示词 × 分辨率 / 画幅 × 种子」的联合结果，照抄旧提示词不是解药。**
→ **机理**：横向运镜在窄画幅里没有位移空间，模型用"复制一个人"补位。

**防复制写法**：`画面中自始至终只有 <Subject 1> 这一位人物`；强调版 `画面里出现的每一处身体、每一段衣袖与每一缕头发都只属于这一位人物`。

**验收注意**：SCRFD 会把石栏雕饰判成脸（score 0.52、尺寸只有真脸 1/3）——**先看 score 与框尺寸，再裁局部目视确认**，别让一次误检把有效结论判废。

## 四、首帧锚定的取舍

| | 挂首帧图 | 不挂首帧图（文字锁起手） |
|---|---|---|
| 起手跳帧 | **会跳一下** | 无（前 5 帧差 0.002–0.09，平滑） |
| 起手复现性 | 高（逐帧一致） | 只能"大致一致" |
| 是否压制运镜幅度 | **否**（实测三镜都完整走出运动，幅度甚至更大） | — |
| 真正的差别 | 在**起点**：不挂首帧时模型会自己发明起始构图 | — |

**推荐**：用**文字锁起手**；**全身镜不宜作拉远镜头的首帧，可作尾帧**。

## 五、跨分辨率复刻

- 「主体静止声明」「起手景别收紧（环境改描述式）」这些结论**都是在 480P 上得到的**，1080P 下**未验证**；
- 跨分辨率 / 跨画幅复用提示词前，先跑 2–3 条确认无回归（例如 D6 揭示 / F3 稳定器 / G1 过肩），再全量铺开；
- ⚠️ **合规检查只验流分辨率，不验内容黑边**——C3 源片自带 baked-in 黑边（内容 AR 1.74:1，模型自己在 4:3 里 letterbox 了），其余 28 条无。

## 六、比较实验的口径纪律

- 条件②（Jojocodex）的提示词**开头多一行强制触发词 `camera motion`**，①②并非逐字相同；③ 各有各的触发词 / 整段 caption。**比较时必须声明这个文本差异**，否则增益归因不成立；
- 每格单样本单种子 → 结论一律标"初级"；
- **480P 素材只判运镜，不判画质、人脸与美感**。
