# 00 · 镜头层核心纪律

> 校准版 v2 · 2026-10-09。含 **DSL 溯源备注**（供你判断某条纪律是「规范」还是「实测」）。
> 凡本文件与旧版 `camera-and-lora.md` 冲突，以本文件为准。

---

## 一、镜头句放在哪里

```
subject_definitions   ← 参考图在此内联（<Picture N> 只在这段出现）
summary               ← 剧情 + 参考关系 + 一句「层级概括」（如「一条连续长镜」「三镜交换」）
retention_analysis    ← 保留等级
detailed_description  ← opening（画面里先出现的东西）→ [Shot N] 镜头句 → action（剧情收尾）
```

- **镜头句只进 `detailed_description`**，紧跟 opening 句之后（`h3-video-prompt-cn` 的六段契约）；
- `summary` 内**至多**一句层级概括，**禁止复述镜头变量**（焦距 / 半径 / 高度 / 角度 / 速度 / 景别 / 摇幅 / 推拉变焦）。
  ✗ 反例：`…机位以恒定半径、恒定高度、恒定焦距、恒定速度顺时针绕她转满一整圈…`（把 summary 写成镜头说明）
- **溯源**：放置规则来自 DSL `models/minimax_h3.md` rule 12 + `scripts/h3_wrappers.py`（Ref2VA → `detailed_description` 的 `[Shot N]`）。

## 二、变量纪律：**不得出现该运镜以外的镜头变量**

| 运镜族 | 允许写的 | 禁止写的 |
|---|---|---|
| **摇镜**（水平 / 垂直） | 摇向 + 摇幅 + 机位恒定 | **焦距**（它本来就没有焦距这个变量——写了等于凭空多给模型一个可动旋钮） |
| **推 / 拉** | 推拉方向 + 起止景别 + **焦距全程锁定**（这句是必写的，用来声明"是机位在动、不是变焦"） | — |
| **变焦** | 用"变焦"表达 + 机位位置恒定 + **透视关系保持不变** | 把焦距数值 / 焦段当自变量 |
| **横移** | 侧移方向 + 末帧落位 + 镜头朝向锁定 | 「视线始终锁定主体」（那是环绕的定义，写了会退化成环绕） |
| **升降** | 升 / 降 + **镜头姿态全程保持水平** | 俯仰（写了就变成"升降 + 摇"） |
| **荷兰角** | 静态倾角方向（左 / 右） | 当成运动写 |
| **翻滚** | 翻滚方向 + 角度 | 省略方向（不写方向则由模型自选，不可复现） |
| **整圈环绕** | **圈数 + 起止时刻（两者都要）** + 闭环收束句「末了回到正面」 | 只给其中一个（见 §五） |

**两条通用铁律**：
1. **不用裸否定**做约束——改用 §三的 12 条正向替换表；
2. **等级不可跨 mode 借用**（这是 DSL 的**调用技巧**，不是镜头结论）：若你用 DSL 查等级，必须显式给 `--h3-profile`，否则查不到。

> ⚠️ **属「书写纪律」而非「实测结论」的条目**（2026-10-09 用户校准）：
> 「主体静止要靠一句**正向静态剧情**（"站在走廊中，单手微微抬起正在安静的思考，发丝与衣摆随微风轻摆"），而不是"不移动、不转身"」——这条来自**否定式禁用令**，不是本轮实测所得。
> 本轮实测只支持这一句事实：**H3 对"主体静止"声明的响应不稳定**（A1 末帧主体姿态仍改变）。

## 三、正向化替换表（12 条穷举 · 含 DSL 溯源）

**为什么要替换**：H3 没有负面提示词，裸否定（点名不要什么却不给替代物）会提高"被提到的事物"出现的概率；更关键的是——**独立成句的否定式在 DSL 自己的实测里把运动压掉了**（见溯源备注）。

**溯源**：DSL 的镜头文本分四层，其中 `negative_clarifier` 层（PROJECT_DEFINED，证据 research/07 D39）**本体就是英文否定句**，字面量在 `scripts/adapters.py`。逐句直译会把它们照搬成裸否定。
另有一条 DSL 自记的反证：**H3LAB-PAN-NEGATIVE-CLARIFIER-01（CL-036）**——在 I2VA / 中景首帧 / `LOCAL_H3_I2VA_PDD8_Q_416` 下，独立成句的 `The camera stays in place.` 在 **3/3 种子里把摇镜压掉了**，同一意思写进单句则不压。→ **句子怎么切会改变结果**，所以正向化不是"措辞洁癖"，是功能需要。

### 3.1 negative_clarifier 层（7 条）

| DSL 英文原句 | `adapters.py` 行 | ✗ 直译（裸否定） | ✓ 正向化写法 |
|---|---|---|---|
| `The camera stays in place.`（摇镜） | 718 / 724 | 机位保持在原地不动 | 机位位置全程固定在同一点 |
| `The focal length stays the same.`（推拉） | 530 / 534 | 焦距保持不变 | 焦距全程锁定在同一档位 |
| `The camera slides sideways and does not turn.`（横移） | 561 | 机位只横向侧移、不摆转 | 机位沿横向侧移，镜头朝向全程锁定在同一方向 |
| `The camera stays level.`（升降） | 556（`stays at the same height`） | 机位不俯仰 | 升降过程中镜头姿态全程保持水平 |
| `{SUBJECT} stays in place and does not turn.`（环绕，derived 层） | 772 | 主体留在原地、不转身 | 主体保持这一站姿与朝向、留在原地 |
| `The camera itself does not move.`（变焦） | 540 | 机位本身不移动 | 机位位置全程固定在同一点，画面变化全部来自镜头变焦 |
| `The camera stays in one spot while it turns.`（甩镜） | 548 | 机位不移动 | 机位位置全程固定在同一点，只有镜头朝向在甩动 |

### 3.2 rig / 装置类（5 条）

| DSL 英文原句 | `adapters.py` 行 | ✗ 直译 | ✓ 正向化写法 |
|---|---|---|---|
| `The camera stays at one fixed spot.`（三脚架） | 401 | 机位不动 | 机位位置全程固定在同一点 |
| `The camera floats smoothly, with no shake.`（斯坦尼康） | 404 | 机位平滑漂浮、没有晃动 | 机位平滑漂浮，画面全程平稳顺滑 |
| `The camera moves very smoothly and level, with no shake.`（稳定器） | 405 | 移动平稳且无抖动 | 机位平稳顺滑地移动并保持水平，画面全程平稳 |
| `The camera moves very smoothly and level through the air.`（航拍） | 383 | 平稳飞行、无晃动 | 机位在空中平稳顺滑地移动并保持水平 |
| `{subj} stays in place and centered and does not turn; the background sweeps behind {subj}.`（SnorriCam） | 584 | 主体不动、背景流动 | 主体保持在画面中央、维持这一朝向；背景在他身后持续掠过 |

**替换式否定仍然安全**：»不沿用 `<Picture 1>`，**改为穿着**…« ——判据是**否定后有没有紧跟「改为 / 换成 / 而是」**。

## 四、书写顺序铁律：画面里「先出现的东西」写在最前面

**这条比措辞更重要，写错整条运镜就不成立。**

| 类型 | 开头必须先写 | 实测 |
|---|---|---|
| **遮挡 / 揭示** | 前景遮挡物（柱子、门框）——**不能**一上来就写主角 | D6：改顺序后起手画面里只有柱子，主体尚未出现 |
| **跨越 / 甩镜 / 航拍** | 门洞、枝叶、花丛或高空全景 | F6 / F8 / F9 / F10 四镜全部命中 |
| **POV** | 主体**不入画**，故不得写景别区间；行走位移写进**剧情** | E1 |
| `summary` | 按同一顺序写 | — |

✗ 反例：`「<Subject 1> 站在走廊中…」开头 + 后面才说被柱子挡住` → 遮挡关系无从建立。

## 五、时刻与配速：**用 `At` 起点–结束点两个时刻描述**

**写法（校准版 v2）**

```
[Shot N] At 00:00.000 起手景别为…；
At 00:09.500 机位已…（运动收束）并停稳。
```

- **配速通过两个时刻给出**：起点的 `At` + 结束点的 `At`，速度由两者之间的时长自然得出；
- **禁止自造时长短语**（「在 3 秒时间内绕她一圈」「第 3 秒开始」）——那等于丢掉速度变量、又塞进一个自造时间变量；
- 时刻**只是引导，会漂移约 ±1 秒**（C6 写 3 秒静止实测 0.67–1.71s 就动；G2 写 5 秒硬切实测 3.54s）。**所以关键动作之间要用「先后次序」文字兜底**，不能只靠秒数；
- 用官方时间语法 `At MM:SS.mmm`，不要自造说法。

## 六、整圈环绕：**圈数与时长必须同时给定**

**校准版 v2**（原表述"禁用 `:FAST`"已升级为更完整的规则）：

| 只给什么 | 会发生什么 |
|---|---|
| 只给圈数，不给时长 | 转多圈冲过正面，或中途停住不完整 |
| 只给时长，不给圈数 | 不转，或转不完 |

**写法（两条都要写）**

```
机位沿弧线绕 <Subject 1> 转满一整圈，末帧回到正面；   ← 圈数（闭环靠这句收束句）
At 00:00.500 开始绕行；At 00:09.500 回到正面收住。      ← 起止时刻（配速）
```

**为什么速度词不可靠（实测证据）**：2026-10-08 实测，写 `:FAST` / "快速" 时，**速度词压过收尾句**——镜头冲过正面继续转第二圈、第三圈，"整整一圈"被吃掉。所以速度交给时刻，不交给速度词；`:FAST` 只留给**蓄意的多圈扫掠**。

## 七、环境写法：**描述式，不要清单式**

**校准版 v2**（原表述"删环境描写"不准确，已重写）：

- **清单式**（逐一点名"柱列、地砖、宫灯、竹丛必须可见"）→ 模型为了把所有元素塞进画面，**把画面推宽**；
- **描述式**（一句说清"主体所处的环境是什么"）→ 不推宽。
- **环境不是删掉，是换写法。**

**效果上限要说清**：改成描述式后主体放大 **2.4–3 倍（2/3 种子）**，但**仍未达到腰部以上（0/3）**。
→ 它是「**别让环境把画面推宽**」的**止损手段**，**不是**「锁半身手段」。

**官方同源依据**：`H3LAB-FRAMING-SCENE-01`（DSL 的 Ref2VA 路由告警原文）：
`describe what environment {SUBJECT} is in, not which environment elements must be visible; Environment lists widened the frame`。

**真要锁住取景的正解（DSL 官方）**：改用 **I2VA 真实首帧**——首帧决定取景 / 高度 / 角度，文字只负责运动。

**同族纪律（F10 事故）**：写任何环境句之前自问「这句是不是在指定机位朝向 / 构图方向？」
——「向纵深延伸」「尽头是」「深处」**都是构图指令**。横移镜要给**走向句**（「长长的外廊从左向右横贯整个画面」），规避"纵深"字眼（前后层次改说「前后错位」）。

## 八、`<Picture N>` 不进 `summary` 与 `detailed_description`

| 段落 | 可否出现 `<Picture N>` |
|---|---|
| `subject_definitions` | ✅ **必须出现**（来源声明：`<Subject 1> 是 <Picture 1> 四视图角色卡中的…`） |
| `retention_analysis` | ✅ 可（图真的作首帧 / 末帧 / 关键帧锚时） |
| `summary` | ❌ 禁止 |
| `detailed_description` | ❌ 禁止 |

**成因**：`<Picture N>` 在规范里的语义就是"一个具体的帧"。写进正在描述画面的正文＝告诉模型"这一帧长成这张图" → **整段运镜会被这张图的构图拽住**。剧情一律用 `<Subject N>` 讲。

**机械自检**：抠出 `summary` 与 `detailed_description` 两段，统计 `<Picture` 出现次数 → **应为 0**。

## 九、起手景别的现实预期（Ref2VA）

- 官方矩阵：「中景及更近」取景 **0/51**；起手命中 6/48，**可测偏差 40/40 全部是"偏宽"**；
- 三条"锁半身"花招全部无效：crop-line 句 ❌、腰部以上裁切参考图 ❌（且破坏下身服装）、构图锚图 ❌；
- 唯一能做的是**环境改描述式**（§七），但上限是放大 2.4–3×，**仍非腰部以上**；
- **实操结论**：同镜跨条件的起手构图**不可逐帧比较**，比较重心放在「起手之后的演变」；
- **全身镜不宜作拉远镜头的首帧，可作尾帧**（A4 即按此设计）。
