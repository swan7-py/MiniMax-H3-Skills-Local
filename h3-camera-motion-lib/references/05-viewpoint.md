# 05 · 视角与机位（E 族）

> ⚠️ **编号陷阱**：演示库与题库**跳号**（没有 E3 / E5），组内实际是 E1 / E2 / E4 / E6 / E7。
> 若外部文档提到"E3"，它指的是本库的 **E4**；"E4"指的是本库的 **E6**。

---

## E1 第一人称 POV

**镜头句**
```
第一人称：镜头即是 <Subject 1> 的眼睛，画面沿他的视线向前展开；
两侧朱红柱列与宫灯自视野两侧向后掠过，左侧庭院里的倒影池、竹丛与松树映入视野，远处是青蓝悬浮科技环与高塔天际线。
机位轻微手持晃动。
他微微抬起右手，银灰护臂与浅蓝袖口出现在画面下缘。
```

- **实测**：✅ 成立（画面即其所见：柱列 / 宫灯 / 倒影池 / 月洞门 / 远山，主体不入画）
- **LoRA**：`fpv_headbob_h3_50`（无触发词）
- **坑（两条铁律）**：
  1. **POV 下主体不入画 → 不得写景别区间**（不要写"取景腰部以上"）；
  2. **行走位移写进剧情，不写进镜头层**（镜头层没东西可写）

## E2 顶拍（垂直向下）

**镜头句**
```
景别为全身景，取景 <Subject 1> 从头顶到脚底；
镜头光轴垂直向下俯拍 <Subject 1>（顶拍）；
机位以慢速垂直上升；
镜头保持水平。
```

- **实测**：✅ **改到露天庭院后才成立**（走廊有屋檐则无从顶拍）
- **坑**：⭐ **俯视 / 顶拍必须先解决"上方遮挡"**——主体若在廊下、屋檐下，顶拍不成立。环境句要写明"站在外廊之外的露天庭院里，头顶是开阔的天空"

## E4 上摇（平视起手）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位在 <Subject 1> 的视线高度、镜头水平起手（平视）；
随后机位以慢速向上仰摇，仰摇约 35 度；
机位位置全程固定在同一点。
```

- **实测**：✅ 末帧露出飞檐与天空
- **坑**：仰摇要给**角度**，且起手必须先声明"镜头水平起手"，否则模型起手就带俯仰

## E6 高角度俯视

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位自较高的角度向下俯视 <Subject 1>，是一个斜角视角；
机位以慢速向下俯摇，俯摇约 20 度。
```

- **实测**：✅ 指标正常
- **坑**：与 E2 顶拍的区别是**斜角 vs 垂直**——俯视是"自较高角度向下看"的斜角，顶拍是光轴垂直向下

## E7 SnorriCam（机身绑定）

**镜头句**
```
景别为中景、取景 <Subject 1> 腰部以上；
机位以跟拍方式随 <Subject 1> 一同移动，<Subject 1> 的整个上半身全程留在画面之内。
他有如把机位带在身上：机位随他同步移动，他在画面中的位置与大小全程恒定，背景持续向后流动。
```

- **实测**：✅ **主体位置稳定 + 背景持续流动**（这是 SnorriCam 的本质判据，两条都要成立）
- **LoRA**：`fpv_headbob_h3_50` 可作对照
- **坑**：**"位置与大小全程恒定"要写**，不写会被读成普通跟拍（主体在画面里会飘）

---

## 本族通用纪律

1. **POV 不写景别**；**俯视类必须先解决上方遮挡**；
2. 机位高度与俯仰是**两个变量**，分开写（E4 平视起手 + 上摇，E6 高角度 + 俯摇）；
3. 绑定类（POV / SnorriCam）靠"**谁在动、谁不动**"界定，把不动的一方写死。
