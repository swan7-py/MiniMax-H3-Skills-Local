# 07 · 双人关系机位（G 族）

> 题材化的双人镜头写法（师门对峙、兄妹叙话一类的**导演意图**）另见
> `xianxia-cinematic-video-director/references/relationship-coverage.md`；本文件只管**H3 上的句子与实测**。

---

## G1 过肩镜头（OTS）

**镜头句**
```
[Shot 1] 画面近景是哥哥的左肩与侧后背——肩头虚化、占据画面左下一角；
景别为中景、取景 <Subject 2> 腰部以上；
过肩机位——机位在 <Subject 1> 的肩后、看向 <Subject 2>，<Subject 1> 的肩头位于近景。
```

- **实测**：✅ **教科书级过肩**（近景肩头虚化 + 对面角色清晰），**四个关系机位里最稳的一个**
- **坑**：**起手必须先写近景肩头**（"画面近景是…的左肩与侧后背"），再写对面的人——顺序反了就不成立

## G2 正反打（一次生成内硬切）

**镜头句**
```
[Shot 1] 画面前段越过哥哥的肩头看向妹妹：近景是哥哥的左肩与侧后背（虚化），妹妹在对面清晰可见、微微侧头听着。
前段：景别为中景、取景 <Subject 2> 腰部以上；
过肩机位——机位在 <Subject 1> 的肩后、看向 <Subject 2>，<Subject 1> 的肩头位于近景。
后段：景别为中景、取景 <Subject 1> 腰部以上；
过肩机位——机位在 <Subject 2> 的肩后、看向 <Subject 1>，<Subject 2> 的肩头位于近景。
```

- **实测**：✅ **一次生成内硬切成立**，但**切点会提前**：写"约第 5 秒"，实测最大单帧跳变落在 **3.54s**（另一条件更早到 2.58s）
- **坑（两条）**：
  1. **别把秒表当硬指标**：用"能切"当结论，切点提前 1–2.5s 是常态；
  2. **每句台词各落一段、不跨切点**，就不必用 `<scenetrans>`（本镜即如此）

## G3 双人同框

**镜头句**
```
[Shot 1] 画面里兄妹两人同时入画——两人在外廊里相对而立、相距约一步半：
哥哥略侧身、把妹妹护在靠里的一侧，一只手负在身后、另一只手抬起来比划着。
景别为中景、取景腰部以上；
双人同框——<Subject 1> 与 <Subject 2> 两人同时在画面内。
```

- **实测**：✅ 两人同框、哥哥抬手比划
- **坑**：两人要写**站位关系**（相距一步半、谁在里侧），不写则位置随机

## G4 双人环绕（180° 半环绕）

**镜头句**
```
[Shot 1] 画面里兄妹两人同时入画——两人在外廊里相对而立、相距约一步半；
景别为全身景、取景两人全身并留出环境；
双人同框——两人同时在画面内；
机位以慢速沿弧线绕两人向镜头右侧移动、弧线约 180 度；
机位始终把两人保持在画面中央；
```

- **实测**：✅ 环绕成立；**整圈版闭环仅 ③b 0.950 达标**（①原生 0.094 / ②Jojocodex −0.035）
- **用户裁定**：**改为 180° 半环绕 + 只用原生**（180° 本就不该按闭环判）
- **坑**：整圈双人环绕若要闭环，**必须挂 360 类 LoRA**

## G5 双人横移

**镜头句**
```
[Shot 1] 画面里兄妹两人同时入画——两人在外廊里相对而立、相距约一步半。
景别为中景、取景腰部以上；
双人同框——两人同时在画面内；
机位以慢速向右横移；
机位沿横向侧移，镜头朝向全程锁定在同一方向。
```

- **实测**：✅ 成立
- **可选增强句**：`机位横移时，近处的柱身与远处的柱列产生不同的相对位移，画面的纵深被拉开`
  ⚠️ 若本镜出现"复制第二个人"的症状，删掉这句——"纵深"是构图指令，会挤掉横向空间

## G6 过肩推近（OTS + 推）

**镜头句**
```
[Shot 1] 画面近景是哥哥的左肩与侧后背——肩头虚化、占据画面左下一角；
过肩机位——机位在 <Subject 1> 的肩后、看向 <Subject 2>，<Subject 1> 的肩头位于近景；
机位起手为取景 <Subject 2> 腰部以上的中景；
机位以慢速向前推进、贯穿全片持续稳定；
焦距全程锁定在同一档位。
```

- **实测**：✅ 末帧收成中近景
- **用户裁定**：**改用原生**（③dolly 没真正推到脸部）
- **坑 / 要点**：⭐ **OTS 的近景肩头天然充当"近景物体"**——推近正好读得出位移，**不必额外补"镜头前要有近景物体"**
- **可选收尾句**：`说到这句话时，机位正好收成她胸以上的中近景；他的肩头随之在画面中变大并滑向画外`

## 本族通用纪律

1. **起手先写近景肩头**，再写被看的人；
2. **正反打的切点会提前**，每句台词各落一段规避 `<scenetrans>`；
3. **整圈双人环绕必须挂 360 类 LoRA**；半环绕（180°）不必，且不该按闭环判；
4. 对白一律 `<d>[Chinese] 台词原文</d>`，**说话人身份 / 动作 / 语气写在 `<d>` 外面**，`<d>` 内只有语言标签 + 逐字原文；`overall_soundscape` **不得重复对白**。
