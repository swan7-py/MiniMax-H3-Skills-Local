# Paper Collage Explainer Generator（本地版 · 逐步确认式）

> 本文件由原始 skill `paper-collage-explainer-generator` 改造为「本地版 · 逐步确认式」。
> **本地化改造总则 v2（纯提示词 · 逐步确认 · 交付物门）**
>
> **⏹ 门控硬规则（真停顿 · 已生效）**：本 skill 中每个 `⏸ 确认门` 与 `⏸ 交付物门` 均为**硬性停止点**，不是建议。固定执行顺序：① 仅输出当前步骤交付物（提示词 / 文本计划 / 分镜脚本等）；② **立即调用 AskUserQuestion 工具**，给三选项「✅ 确认，继续下一步」「✏️ 修改当前步」「⏸ 暂停 / 停止或换方向」；③ **等待用户回复**，本回复内**绝不可预生成任何后续步骤**（即使你觉得能一次写完）。任一 `⏸` 门不得跳过 / 合并，也不得仅用一句"请确认"文字代替——必须用 AskUserQuestion 真正阻塞。
> 1. **生图只给提示词，不调用任何生图工具**：每片段静帧等生图步骤只输出文生图提示词；用户自行用任意工具生成图像，并把**图像文件路径或地址返回给我**。本 skill 不硬编码任何 ComfyUI 工作流路径。
> 2. **每一步都确认 + 交付物门（核心规则）**：每个步骤产出后我都会暂停，等你「确认 / 修改」。生图步骤必须等你**返回图像地址**后，才进入视频提示词步骤（视频提示词以静帧为参考图，I2V from still）。
> 3. **视频提示词调用 `h3-prompt-writing` skill**：视频提示词均调用用户级 `h3-prompt-writing` skill（纯文本、无需 API）来写；以你返回的静帧为参考图，按其 I2VA / Ref2VA 结构输出完整 H3 视频提示词，并附端口 / 顺序 / 时长 / 分辨率设置建议，由你在本地 H3 节点自行执行。 H3 特殊占位符 `<d>`/`</d>`、`<|lyrics_start|>`/`<|lyrics_end|>`、`<|caption_start|>`/`<|caption_end|>`、`<|cutoff|>` 及其固定 id 见 `h3-prompt-writing` 的「Special Tokens」节，写对白/歌词/字幕时严格照用。
> 4. **语音 / 音乐先询问（已升级为「音频模式门」）**：进入流程第一步（方向/简报锁定）时，必须先用 AskUserQuestion 问你**音频方案**，二选一：
>    - **A) 统一 H3 音频**：旁白 + 对白 + BGM 全部由 H3 原生音频驱动生成（最省事，音色/配乐与画面同步，无需外部文件）。
>    - **B) 分离生成**：旁白/对白只给提示词（你用任意 TTS 工具，推荐用「参考/音色克隆」模式保证跨镜头一致；不绑定 MOSS-TTS）、BGM 用 ACE-Step 1.5 本地生成（调用 `ace-step-1.5-prompt-writer` skill）、对白分别生成，后期合成。
>    - 记录你的选择，后续「视频提示词步骤」与「音频步骤」依此分支执行。
> 5. **旁白/对白一致性（分离模式必做）**：若选 B 且含旁白/对白，提醒你把【音色参考文件】（.wav/.mp3，代表目标音色）放到**当前项目文件夹（你运行本 skill 的工作目录）**，并在调用 TTS 时使用「参考模式 / 音色克隆」，确保多镜头音色统一；若你未提供该文件，先暂停请其提供，禁止无参考直接生成（否则各镜头音色漂移）。
> 6. **BGM 分离 -> 视频提示词只规划视觉（重要）**：若选 B，BGM 由 ACE-Step 1.5 单独生成，因此**调用 `h3-prompt-writing` 写视频提示词时不可规划 BGM/旁白/对白的音频出现**（如"音乐渐强""旁白响起""对话切入"等），只规划镜头/动作/画面；音频在后期合成。若选 A，视频提示词可正常包含音频驱动指令，无需单独生成音频。
> 7. **删除自动剪辑 / 拼接**：改为提供"剪辑思路"。
> 8. **规划 / 分镜 / 排版等文本方法论沿用原 skill**。
> 9. **删除"表情图"相关提示词**。

## 默认创意目标（沿用）
- 画幅 16:9；每段约 4s；默认保留/生成拼贴 SFX，不加 BGM/语音/字幕（除非你确认）；视觉为高端编辑 halftone 纸拼贴；运动为触感定格组装；默认视频模型标注 MiniMax-H3。

## 音频策略（沿用 + 本地化）
> ⚠️ 音频模式门：仅模式=分离 时单独生成 BGM/语音（BGM 用 `ace-step-1.5-prompt-writer`、语音只给提示词（把【音色参考文件】放项目文件夹，用任意 TTS 参考模式保证跨镜一致））；模式=统一H3 时由 H3 原生生成。
> ⚠️ 音频模式门：仅模式=分离 时单独生成 BGM/语音（BGM 用 `ace-step-1.5-prompt-writer`、语音只给提示词（把【音色参考文件】放项目文件夹，用任意 TTS 参考模式保证跨镜一致））；模式=统一H3 时由 H3 原生生成。
默认交付＝含拼贴 SFX、无 BGM/语音/字幕。涉及 BGM/语音/字幕时先问你「用云端生成 or 只给提示词」；若只给提示词，输出对应风格提示词。其中 **BGM 部分优先调用 `ace-step-1.5-prompt-writer` skill** 产出 ACE-Step 1.5 提示词（Caption/Lyrics/Metadata）；语音部分只给提示词（不绑定具体 TTS 工具，你用任意 TTS 生成）。

## 全局风格规则（沿用）
统一视觉、控纸纹强度、统一色调、定格组装感（逐片出现/滑入/弹/压平/暂停/锁）、批次协调、16:9 分层、强调纸拼贴工艺。

## STEP 1：解析输入
同原 skill：核心义/情绪/动作动词/视觉隐喻/3–6 关键纸组/音频暗示；故事拆 3–6 beat。
- ⏸ **确认门**：解析呈现后暂停，等你确认隐喻与 beat 拆分。

## STEP 2：门1 制作计划文档批准
同原 skill：Brief + 视觉隐喻 + 脚本/视觉 beat 轨 + 分镜；先给默认媒体说明（拼贴 SFX 保留，BGM/语音/字幕不加），可选问你是否要；批准后再生媒体。
- ⏸ **确认门（硬确认）**：制作计划呈现后暂停，等你批准/修改后才进 STEP 3。

## STEP 3：静帧规格
同原 skill：含风格签名（flat bold color field、黑白 halftone 剪贴、选择性卡纸重色、暖奶油 keyline、软纸影、细无涂布纸纹、精 hand-torn 边、层缝）。
- ⏸ **确认门**：规格呈现后暂停，等你确认。

## STEP 4：生图提示词（只给提示词 + 交付物门）
**本 skill 不调用云端/ComfyUI 生图**。改为：
**调用用户级 `image-prompt-writer-local` skill** 生成富结构提示词：传入 场景类型=海报/抽象（纸拼贴静帧）、风格上下文=本片纸拼贴统一风格锚（平色场+纤维、黑白 halftone 剪贴+卡纸重色、暖奶油 keyline、软纸影、no 3D/CGI/photo/neon/glass）、主体与要求=每段（清晰主体层次、3–6 大纸组、无可读文字/UI/logo）。它返回「通用风格锚 + 每段静帧四段式详描」，你原样呈现。
**本步骤产出**：每段静帧的**文生图提示词**（来自上一步 skill 输出；风格签名已写入提示词）。
- ⏸ **交付物门（必过）**：提示词给你后暂停。请你用任意工具生成静帧图像并**返回图像地址（=动画完成末帧/视频参考图）**。收到后才进入 STEP 5/6。
> 确认卡：批准/改/重生成某张后再进视频。

## STEP 5：定格组装计划
同原 skill：从匹配静帧底色色场开始→纸件滑/弹/压入→主体进入→次物件逐个组装→锁成静帧→尾持。
- ⏸ **确认门**：组装计划呈现后暂停，等你确认。

## STEP 6：视频提示词（调用 h3-prompt-writing + 设置建议 + 交付物门）
**不再由本 skill 直接写 H3 提示词，改为调用 `h3-prompt-writing` skill**：
- 输入：STEP4 返回并批准的静帧图像地址 + STEP5 定格组装计划。
- **调用用户级 `h3-prompt-writing` skill**（纯文本、无需 API），按其 I2VA / Ref2VA 结构输出完整 H3 视频生成提示词（I2V from still，含定格组装运动指令：色场起始→逐片滑入/弹/压平/暂停/锁→尾持静帧+拼贴 SFX）。
- 并附设置建议：
  - 参考图 = STEP4 静帧（批准版）→ 接入 H3 节点「图像参考 / image reference / 首帧」端口（I2V from still）
  - 音频（依总则「音频模式门」分支）：模式=统一H3 时，BGM/语音由 H3 原生生成；模式=分离 时，本视频提示词**仅规划视觉**，不写 BGM/语音出现指令——SFX 保留、BGM 由 `ace-step-1.5-prompt-writer` skill 生成 ACE-Step 1.5 提示词（Caption/Lyrics/Metadata）、语音只给提示词（把【音色参考文件】放项目文件夹，用任意 TTS 参考模式生成），分别接「音频输入」端口。
  - 时长 = 约 4s/段（或你定）；分辨率 = 与静帧一致（默认 16:9）；其余你自定
  - 模型标注 MiniMax-H3；本地用 Wan I2V 亦可（首帧接静帧）
- **本步骤产出**：完整 H3 视频提示词 + 端口/顺序/时长/分辨率设置建议。
- ⏸ **交付物门（可选）**：你确认提示词后自行在 H3 执行，返回成片地址（可选）。

## STEP 7：质量评审
同原 skill：隐喻无需文字可读；静帧层次/对象数/组装可见/定格感/纸纹受控/色调一致/终帧近静帧/无杂字。
- ⏸ **确认门**：评审呈现后暂停，等你确认或打回重做。

## STEP 8：剪辑思路（替代可选自动组装）
- 多片段故事视频：按确认分镜顺序拼接，默认保留各 clip 原生拼贴 SFX。
- 工具建议：ffmpeg/本地剪辑软件硬切；BGM/语音仅在你确认后混音（与 SFX 共存不替换）。
- 交付：每段给最终 B-roll 路径/组装视频路径 + 静帧路径 + 一句隐喻说明 + 媒体注记。
