# Creative DNA 创意机制库（T8mars 案例库方法论）

> 来源：github.com/T8mars/minimax-h3-prompt-skill-T8（T8 Creative DNA Prompt Library，v1.4.7）。
> 定位：写视频提示词时**提取可复用创意机制**的案例索引。本库不保存原始提示词文本，只拆解可迁移的底层"创意机制"。
>
> ⚡ **完整案例库已收录为独立 skill `creative-dna-catalog`（613 个案例全文 + 分类索引）**——实际检索与调用请用那个 skill，本文档仅保留方法论总纲。

## 四条方法论原则

1. **机制拆解（Creative DNA）**：每个案例不保存提示词原文，而是拆出可复用的底层机制——镜头语言、叙事节拍、证据结构等。
2. **以成片为准**：只保留**被画面证明**的机制，不以长提示词的承诺为准（实测案例：13.373s 样片与"15s 竖屏完整导弹追逐"文本失配 → 只保留画面实际呈现的距离反转、惊吓、手势降级机制）。
3. **反复制重构**：机制被抽象化后迁移复用，禁止照抄原文；贡献需经"完整媒体解码、时长核对、机制拆解、反复制重构、双模型编译"。
4. **双模型编译**：同一机制同时编译为 MiniMax H3 与 Seedance 2.0 两套提示词。

## 使用方式

1. **取机制骨架，不抄提示词**：从对应类别取 1–2 个机制作为分镜的叙事/运镜骨架，再按用户的参考图、角色卡、素材重构。
2. **与 H3 结构对接**：机制决定"分镜里发生什么、镜头怎么动"，H3 六段结构（base-en.txt / ref-en.txt）决定"怎么写出来"——两层不混淆。
3. **以能被画面验证为准**：写入提示词的每个机制都应能在成片中检验；无法验证的修辞（"史诗感""高级感"）不写。
4. **双模型意识**：同一机制若需迁移到 Seedance 2.0，重新编译而非直译；注意两模型对时长、标签、音频能力差异。
