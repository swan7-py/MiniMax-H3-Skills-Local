# 音频参考（`<Audio N>`）：关系标记 · 说话人编号 · 实测判据

> 上游契约：`ref-en.txt` §2.4 / §4.2 / §5.4 定义**语义**（`<Audio N>` 是什么、四种关系标记各表示什么、`(Sx)` 如何编号）。
> 本文件只补**实测判据与踩坑**——「跑出来什么样算对、算错、怎么修」。来源：H3 音频参考能力测试（2026-10-12 ~ 10-14，27 条成片，SelfLift dasiwa × FreeVideo 双管线、同提示词同 seed 对照）。

## 〇、四种关系标记的实测基线

| 标记 | 官方语义 | 实测 |
|---|---|---|
| `fully_copy` | 完整源音频作为成片完整最终音轨 | **音乐近乎无损**：r≥0.99、**零位移**（两管线一致），复现率 99–100%。**语音带 ~0.45s 系统位移**（包络相关需 +0.45s 偏移）。**跨硬切行为因管线而异**——SelfLift 切点前 0.9923 零偏移 / 切点后 0.8821 @+0.45s（第二镜语音被**重新生成**）；FreeVideo 切点前 0.9819 / 切点后 **0.9942 均零偏移** |
| `partially_copy` | 只复制部分时间线或选定音频层，或复制后增删替换 | **区间声明不被遵循**。声明「仅复制 0–5.0s」实测：前段只复刻约 2.75s（3–5.85s 静默），5s 后仍出现大量语音（5.85–9.9s）；0–5s 精度仅 r=0.5274 @−1.80s。→ **需要精确区间时用后期剪辑切分** |
| `reference` | 不复制信号，只参考音色/节奏/风格/内容/质感 | 迁移能力取决于**有无性别对手**：单人同性别 → 近无损；单人跨性别 → 被往表观性别方向拉；双人同框 → 按表观性别分配，需「性别倒错声明」接管。**根本机制与判定陷阱见 §一** |
| `weak_reference` | 只保留类别或氛围的宽泛相似 | **未测，且不建议投入**——语义太弱、对音色类测试无增量；唯一可能场景（氛围参考）与已撤的环境声复刻重叠 |

**复刻精度判据（可脚本化）**：取成片音轨与源音频的 0.05s RMS 包络，做 ±2s 内互相关取最佳值。
- 音乐类：**r≥0.98 且零偏移**为达标。
- 语音类：必须同时报「最佳偏移」——**+0.45s 附近的常驻位移是系统性的**（不是随机误差），零偏移反而对不上。

## 一、角色形象先验 > `<Audio N>` 音色参考（`reference` 的根本机制）

**模型在「角色形象」与「参考音色」冲突时，不是二选一，而是加权折中——权重强烈偏向角色形象。**

| 场景 | 实测表现 |
|---|---|
| **同性别**（角色女 · 参考女） | 参考被完整采纳：云朵 307.7Hz → 363.6Hz |
| **跨性别**（角色女 · 参考男） | 参考被**往角色的表观性别方向拉**：夜语 142.0Hz → 220.2Hz（+55%）；拉扯幅度取决于参考样本自身的「性别信号强度」——鹄仙本声 151.0Hz → 156.9Hz（+3.9%，几乎完全迁移） |
| **双人同框**（每镜各一人说话） | 权重完全倒向角色形象：两路参考各归其表观性别（S1 男 113Hz / S2 女 296Hz），**强化提示词也压不动** |

### ⚠️ 关键限定：F0 落在正确性别区间 ≠ 音色被复刻

F0 落在男声区 / 女声区，有两种完全不同的成因，**单看 F0 分不开**：

| 成因 | 表现 |
|---|---|
| **(a) 真迁移** | 模型调用了参考样本的音色 → 听感与参考相似 |
| **(b) 按角色形象脑补** | 模型看到「男性角色」就生成一个**该性别的通用声音** → F0 同样落在男声区，但**音色质感不是参考的那个** |

**实测（2026-10-14）**：男性角色 + 男声 `reference` 参考（配 `partially_copy` 伴奏层），用户试听判定「**音色像，但更像按男性自动生成的、而不是参考我的音色，而且特别难听**」——即 (b)。而此前的 A1 本声（151→156.9Hz）曾按 F0 判为「几乎无损迁移」，说明**旧判据把 (b) 误认成了 (a)**。

**⇒ 判定纪律**：**音色迁移是否成立只能靠试听；F0 只能证伪（男角色出女声＝确定失败），不能证正。**

**⇒ 工程推论**：想让参考音色真正生效，**先让角色形象与音色不冲突**。这正是「性别倒错声明」起作用的机制——`<Subject 1>` 写成「**少女模样的男子**」不是修辞，而是**先解除「角色形象 vs 音色」的冲突**，让音色参考有机会被采纳（写法见 §四）。

## 二、Sx 编号必须与「接线顺序」一致（2026-10-14 实测 · 铁律）

`ref-en.txt` §5.4 已规定 *"Assign `(Sx)` once according to the order of actual vocal events in the target video."*
**补充：接线侧的编号顺序也必须对齐。**

**问题**：提示词按「实际发声顺序」编 `Sx`，而接线（`references` 数组 / 节点端口）按「素材上传顺序」编 `<Picture N>` / `<Audio N>`。两套顺序不一致时，四条编号线互相错位，模型收到矛盾的指涉。

**做法**：让 `Subject N` = `S N` = `Audio N` **三线同号**
1. 先按实际发声顺序定 `S1` / `S2`；
2. 让该说话人的视觉主体 `<Subject N>` 与音色参考 `<Audio N>` 取同一个 N；
3. 接线数组 / 端口顺序**也**按这个 N 升序排。

**交付前机械自检**：

| 检查项 | 达标形态 |
|---|---|
| 首个出现的 `(Sx)` | 是 `(S1)` |
| 每个 `<Audio N> 是<Subject M> (Sx)` | M == N（同号） |
| 分镜正文里该 Subject 的 `(Sx)` | 与 definition 一致 |
| 接线数组顺序 | 与 N 的升序一致 |

## 三、台词约束不可省（2026-10-14 踩坑）

`ref-en.txt` §5.4 末句：*"When only timbre, rhythm, emotion, or delivery is referenced, do not carry the original dialogue from the reference audio into the target video."*

**这条约束必须保留**，哪怕提示词其余部分已简化成纯绑定句。

- **踩坑实录**：把 `<Audio 1>` 定义简化成「`<Audio 1>` 是`<Subject 1>` (S1) 的音色参考；」后，**单人单句**场景台词跑偏——成片与参考音频的包络相关升到 0.66（参考音频的语音节奏被带入）、开口时间晚 1.5s、语音碎段化。补回约束后降到 0.41–0.56，开口提前到 3.95s。
- **为什么双人场景不暴露**：`<d>` 内有多句交替，模型有内容可跟；**单人单句最易踩**。
- **保留写法（正向化）**——三处任选其一即可，建议齐写：

| 位置 | 补写内容 |
|---|---|
| `<Audio N>` 定义 | `…只参考其音色与说话方式；目标台词为全新的独立内容，与参考音频的语句无关。` |
| `retention_analysis` | `…以该男声说出全新台词，目标台词为 <d> 内标注的全部内容，不复制原音频信号。` |
| `detailed_description` | `…他的嘴唇随台词开合，整段视频的台词以这一句为全部内容；` |

## 四、双人 / 多说话人：让「一个画面只出一个说话人」

**背景**：双人同框时模型要为每个说话人找归属，画面人物一多就锁不住（实测：音色方向对了，但两个角色都张嘴、或说话人与台词错配）。

### 3.1 性别倒错声明（音色与外表性别相反时）

| 目标 | `<Subject N>` 写法 |
|---|---|
| 外表少女 · 内在男声 | `<Subject 1> 是<Picture 1>四视图角色卡中**少女模样的男子**：…**他的**脸型、五官、发型与服装均以<Picture 1>为准，音色是<Audio 1>` |
| 外表男子 · 内在女声 | `<Subject 2> 是<Picture 2>四视图角色卡中**年轻男子的女子**：…**她的**…以<Picture 2>为准，音色是<Audio 2>` |

- **倒错声明 + 代词同步**是音色对调的必要条件（原来只写「少女」时，音色被表观性别覆盖）。
- **音色绑定用纯引用**：`<Subject N>` 尾句只写「音色是 `<Audio M>`」；`<Audio M>` 的 definition 只保留绑定句。
- **分镜里写「用 `<Audio M>` 的音色」**，不要写音色形容词。

### 3.2 过肩镜头（每镜只让一个角色正面入镜）

双人对戏若仍锁不住，把两镜都改成**过肩**——机位置于 A 的肩后、画面主体是正对镜头的 B，A 只以肩背与后脑做前景虚化。实测：画面中央始终只有一人正面入镜，说话人锁定最稳。

```text
[Shot 1] 过肩镜头，机位置于<Subject 2>的左肩之后，画面主体是正对镜头的<Subject 1>并占据画面中央；<Subject 2>以左肩与部分后脑出现在画面近侧边缘、呈前景虚化；<Subject 1> (S1) 用<Audio 1>的音色看向<Subject 2>的方向开口说：<d>…</d> 她的嘴唇随台词开合…；前景的<Subject 2>在本镜中嘴唇保持闭合。
[Shot 2] At 00:05.000，镜头切换为反向过肩，机位置于<Subject 1>的右肩之后，画面主体是正对镜头的<Subject 2>并占据画面中央…
```

### 3.3 每镜收尾句（正向）

`…这一镜的台词由 <Subject 1> (S1) 独自说完。` —— 不写「另一人不要说话」，写另一人的**正向状态**（`嘴唇保持闭合`）。

## 五、正向单人约束（抑制四视图参考卡的分格泄露）

**症状**：单镜长段 + 四视图角色卡作参考时，成片出现**多个人物**，甚至把参考卡里的**面部特写格**当成画面元素渲染进去（实测：画面左侧出现一个四视图式的脸）。

**修法——五处齐写正向约束**：

| 位置 | 补写内容 |
|---|---|
| `<Subject 1>` 尾句 | `她是画面中唯一的人物。` |
| `summary` | `…<Subject 1> 独自站在…` |
| `retention_analysis` | `…她在整段视频中是画面里唯一的人物。` |
| `detailed_description` 开头 | `整段画面是单一连续场景，由同一个固定机位完整拍摄，<Subject 1> 独自一人入镜，全身完整可见，画面中只出现这一位少女。` |
| 换装 / 变身句内部 | `…继续独自站在画面中央…` |

**实测**：加上后第一段与第三段回到单人、分格泄露消失。**但换装时刻附近仍可能分裂出第二人**（第一次换装后出现、第二次换装后消失）→ 约束需**在换装句内部重复**，不能只在开头声明一次。

## 六、音频类提示词的否定式白名单

`references/negation-guard.md` 的两级判定（L1 词表 + 白名单）同样适用。音频类有两处**易误伤**，须列入白名单：

| 句式 | 判定 | 理由 |
|---|---|---|
| `只参考其音色与说话方式，不复制音频信号` | ✅ 安全 | `reference` 标记的规范固定表述（官方示例同款） |
| `目标台词为全新内容，不复用原音频的语句` | ✅ 安全 | 语义限定，非「点名画面里不要出现某物」 |
| `<d>…</d>` 内的台词原文 | **整段豁免** | 台词逐字保留，不参与闸门（如「有些门一旦关上，就再也不会打开」） |

**闸门脚本必须带 `<d>` 段豁免**，否则会拦下正常台词。
