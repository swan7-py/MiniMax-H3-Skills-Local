# 动作迁移类（Ref2VA 六段）

> 来源：2026-10-14 赛博朋克滑板动作迁移实测 —— 同参考视频、同 seed、同 9:16、同底座的前提下，
> 5 版提示词 × 2 条管线（SelfLift dasiwa / FreeVideo VDN），用逐帧 Farnebäck 光流做定量判据

---

## 一、与「替换 / 编辑类」的分野

| | 本类（动作迁移） | 替换 / 编辑类（见 `editing-and-replacement.md`） |
|---|---|---|
| 源视频提供什么 | **运动、机位、硬切与节奏** | 被编辑的画面本身 |
| 成片画面 | 新片：角色 / 场景是自建的 | 还是那条源视频，只改其中一块区域 |
| `<Video N>` 的 retention | `attribute_transfer` | `partially_preserved` |
| 任务类型 | `[reference generation]` | `[video editing + reference generation]` |

**判据一句话**：成片出来后，源视频的画面内容还在不在？不在 → 本类。

## 二、症状 → 先排技术故障再改提示词

**症状**：成片动作与参考视频差异极大，**反而与提示词文字一致**。

动手改提示词之前，先排除两个技术原因（这两条最常被误判成"模型不行"）：

1. **接线**：`119.ref_videos.ref_video_0 → ["<VHS_LoadVideoPath 节点 id>", 0]`，且 `force_rate` = 参考视频帧率、`frame_load_cap` = 目标帧数。
2. **真的被吃进去了**：看 prompt 里有没有 `ref_tokens`（本次实测 **59968 / 64368** 有值即已编码进上下文）。

**接线没问题 ⇒ 一定是提示词问题。**判据：两条完全不同的底座跑出**几乎相同**的运行数据 ⇒ 不是底座 / 管线变量，只可能是提示词。

## 三、根因：动作被写成了"可表演的台词"

曾翻车的写法（`detailed_description` 逐镜白描动作）：

> ✗ 约在第 3 秒，她**前脚压住板尾猛然起跳**，**板体离地翻起**、她整个人**腾空**、**双臂向两侧展开**，约半秒后**连人带板落回地面**
> ✗ 她**脚尖拨板使板体沿长轴翻转一整周**
> ✗ 她**压低重心蹲伏**、**贴着镜头快速横穿**
> ✗ 镜头保持中景，**随她靠近缓缓推近**

这是**在给模型写剧本**——文字信号强过视频参考，模型就照文字演一遍。

修正写法：

> ✓ 她的**位置、朝向、身体轮廓、位移轨迹与移动速度、姿态与占位体积**逐帧沿用 `<Video 1>` 中对应时刻的运动
> ✓ 她与 `<Subject 3>` 之间的**踩踏位置、接触点与贴合关系**同样沿用 `<Video 1>`
> ✓ 出现在画面里的每一个动作，都是 `<Video 1>` 中已经存在的那些

## 四、写法规程（六条）

1. **零动作白描** —— 不写任何可独立表演的动作词。本项目实跑收集的词表（交付前脚本化拦截）：
   `压住板尾 / 起跳 / 腾空 / 翻起 / 板体离地 / 双臂向两侧展开 / 翻转一整周 / 蹲伏 / 快速横穿 / 匀速滑入 / 重心 / 顺式 / 打板`
   判据：这段话能不能让人**不看参考视频就演出来**？能 → 是白描，删。
2. **运动归属七维逐镜声明** —— 位置 / 朝向 / 身体轮廓 / 位移轨迹与速度 / 姿态 / 占位体积 / 接触关系（＋逐镜机位、硬切点、节奏），统一措辞「**沿用 `<Video N>` 对应时刻的运动**」。**每个空间段都要挂一句**，不是只在定义段说一次。
3. **零机位白描** —— 机位与镜头运动同样归 `<Video N>`，不自行指定推拉摇移。
4. **`<Video N>` 定义升格为"全片运动与机位的唯一来源"**，并在定义里把七维逐项列名（不是"提供动作的参考视频"这种一句话版本）。
5. **收口句必写**（`{{NO_ADDED_EVENT}}` 的正向写法）：「出现在画面里的每一个动作，都是 `<Video N>` 中已经存在的那些。」——放 `summary` + 末镜各一处。
6. **保留 `At MM:SS.mmm` 硬切时刻**；场景与道具仍可自建，身份内联 `<Subject 1>`。

> 注意：`overall_soundscape` 里的「起跳与落板闷响」这类**声音描述保留**——声音本来就该具体，且它不是视觉动作白描。视觉段（切到 `overall_soundscape:` 之前）必须零动作白描。

## 六、⭐ 字数配额与精简边界（本轮最重要的定量结论）

同一 `<Video N>` 体系下，**提示词越短，三项运动判据越好，且单调**：

| 版本 | 一采 / 二采 | 提示词字数 | 运动能量 | 与源片时序 r | 光流方向一致度 | 峰值帧（源片 **149**） |
|---|---|---|---|---|---|---|
| **源片** | — | — | **1.935** | — | — | 149 |
| v1 动作白描版 FreeVideo(VDN) | 768×1344（1.03MP 单采） | ≈2600，含动作白描 | 0.966 | −0.182 | 0.096 | 33 |
| v1 动作白描版 SelfLift(dasiwa) | 0.9 / 1.5 | 同上 | 0.963 | −0.039 | −0.056 | 112 |
| v2 改归属句，未精简 | 0.4 / 0.9 | 2622 | 0.552 | −0.015 | 0.132 | 151 |
| v3a（只提分辨率） | 0.9 / 1.5 | 2622 | 0.726 | 0.143 | 0.169 | 101 |
| **v3b（精简）** | 0.9 / 1.5 | **1701** | **1.524** | **0.437** | **0.302** | 17 |
| v3c（极简） | 0.9 / 1.5 | 1416 | **1.650** | **0.495** | 0.262 | 19 |

**结论**

- **剧情叙述 + 大段环境描写与运动抢配额**（H2）。2622 → 1701 字，能量从 0.726 拉到 1.524（**2.1 倍**），r 从 0.143 拉到 0.437。
- **一采分辨率过低也会抹掉运动结构**（H1，次要但必要）：0.4 → 0.9MP 让 r 首次转正。
- ⛔ **精简的边界＝不能砍掉"题材识别特征"**：v3c 把 `<Subject 2>` 压成一句名字、无外观描写 → 赛博朋克公园**退化成普通公园**。
- **取向：1500–1700 字**。❗身份段、`<Video 1>` 七维归属、`retention_analysis`、每镜归属句、`At` 硬切、收口句**一律不精简**；精简的对象是 summary 的剧情叙述、场景段的长描写、音效段。

## 七、验收：光流四判据

脚本：`_frames/diag_motion.py`（Farnebäck，逐帧对齐源片序列），判据四项：

| 指标 | 含义 | 合格线 |
|---|---|---|
| **运动能量比** | 成片 / 源片 mean 能量 | **0.7 – 1.3×** 源片 |
| **与源片能量时序相关 r** | 运动的"节拍"是否同步 | **> 0.4** |
| **逐帧光流方向一致度** | 每帧运动方向是否相同向 | **> 0.15** |
| **峰值帧位置** | 动作最激烈的时刻是否对得上 | 接近源片峰值帧 |

**已知残余问题（时间轴被压缩）**：达标版的峰值帧落在前 1 秒（17 / 19），而源片在 8.0 秒。
逐秒能量曲线显示模型把整段动作**压缩到起手 1 秒内演完**——**不是运动几何错了，是节奏分布错了**。
`At` 硬切时刻只对切点有效、**对段内节拍无约束**。后续可试的方向：逐镜写"该镜运动持续整个镜长"的时段声明。

## 八、不属于本文件能解决的（别再归因到提示词）

成片**清晰度**（尤其高速运动的小物体看得清不清）**不受本套写法支配**，别在这里改：

| 因素 | 结论 |
|---|---|
| **σ 低噪区（σ < 0.5）有没有采样步** | **决定性**。低 σ 定边缘与纹理锐度；官方满血那条工作流的表是「前八位与我们逐位相同，后面再补 `.4737 .1579`」,补的正是这一段。可参考 `H3SigmaRefiner` 或换官方 ManualSigmas 表 |
| VAE 精度 fp16 vs int8_convrot | **已证伪**：往返 PSNR 差 0.00 dB；同 latent 换 decoder 差 57.55 dB / 高频 −0.3%。别往这使劲 |
| 一采分辨率 + latent upscale | 0.4MP 起步时小物体 token 太少，upscaler 只是插值 |
| turbo / 步进蒸馏 LoRA 被旁路 | 会让 8 NFE 裸 int8 严重欠采样。（注意：这类 LoRA 属"加速"性质，不是"效果"LoRA——项目铁律「动作用 `<Video N>` 承载时不加效果 / 运镜 LoRA」**不适用于它**） |
