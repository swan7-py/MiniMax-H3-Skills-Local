# 书写顺序铁律：画面里"先出现的东西"写在最前面

> 来源：H3 运镜对照测试（用户诊断 D6 后确立；F6/F8/F9/F10 四镜全部命中验证）

---

## 一、铁律

**`detailed_description` 的第一句，必须是画面 t=0 时真正出现在镜头里的那个东西。**
不看叙事顺序、不看人物重要程度——**只看观众第一眼看到什么**。

写反的后果：模型把"最后才出现的东西"提前画出来，遮挡/揭示/越障的关系直接消失。

## 二、必须先写"起手物"的三类镜头

### ① 遮挡 / 揭示类（先藏后亮）
**✗ 错误**：`<Subject 1> 站在走廊中，单手微微抬起正在安静的思考；他身前有一根朱红木柱挡住视线…`
→ 等于一上来就把主角写进画面，遮挡无从建立。

**✓ 正确**：`画面起初被一根朱红木柱的柱身挡住——柱身占据画面左侧、清晰锐利，柱子后方的庭院与外廊是虚的。`
→ 主角的出场放到揭示动作**之后**：`柱子移开、焦点落定之后，他从虚到实清晰地显现出来。`

### ② 跨越 / 甩镜 / 航拍类（起手是一个物体或一大片环境）
| 镜 | 起手物 | 正确开头 |
|---|---|---|
| 穿越镜头 | 门洞 | `画面起初是廊道尽头的月洞门——圆形的门洞把画面框住，门洞里透出门后明亮的庭院与竹丛。` |
| 遮挡穿越 | 贴镜头的前景枝叶 | `画面起初被前景的一丛花与枝叶挡住——枝叶贴着镜头、清晰可辨，后面的外廊与庭院是虚的。` |
| 航拍 / 极远景 | 高空全景 | `画面起初是高空俯瞰下的整座庭院与外廊：<Subject 1> 站在廊道中，从上往下看只是一个小小的身影…` |
| 视差运镜 | 近景前景物 | `画面近景处始终有一根朱红木柱的柱身——它位于机位与 <Subject 1> 之间，柱身清晰锐利。` |
| 甩镜（反打式） | 起点物体（如一朵花） | `画面起初落在外廊边上的一丛花上——花朵位于画面中央、清晰可见，随风轻摆。` 随后 `镜头以极快的甩镜向右甩过、落到 <Subject 1> 身上…` |
| 遮挡穿越（穿过物体） | 前景遮挡 | 同上，穿过之后再落到主体 |

### ③ POV / 第一人称类
- **不得写景别区间**（POV 下主体不入画，不存在"取景主体到哪里"）；
- **行走带来的位移写进剧情，不写进镜头层**：`<Subject 1> 正沿廊道向前走着，视野沿廊道向前延伸…`；
- 不写"他不出现在画面里"这类**否定式**（改成正向：镜头即是他的眼睛，画面沿他的视线向前展开）。

## 三、连带规则

1. **`summary` 必须按同一顺序写**——summary 与 detailed 的先后关系不一致，会互相拉扯；
2. **`action`（镜头句之后的剧情收尾）才是主角"登场后"的动作**；顺序错位时把主角的动作整段挪到 action；
3. **POV** 下若要有主角台词，写成**画外音**并说明为何看不到口型；
4. 判断自检一句话：**"把这段提示词念一遍，第一句描述的东西，在 t=0 的画面里看得到吗？"**
