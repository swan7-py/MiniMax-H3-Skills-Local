# 参考图的两种角色：构图锚 vs 内联定义

> 来源：H3 运镜对照测试（B2 拉镜头"落回场景图斜角构图"的根因诊断）

---

## 一、判据（H3 规范 §2.2）

> 图片**只有当首帧 / 关键帧 / 末帧 / 编辑关键帧 / 构图锚**用时，才独立成 `<Picture N>` 一条；
> **只用来定义角色、场景、服装或风格的图，不应独立成条，而应写进对应的 `<Subject N>` 里。**

| 参考图用途 | 正确写法 |
|---|---|
| 首帧 / 末帧 / 中间关键帧 / **构图锚** | **独立成 `<Picture N>`**，并在 `retention_analysis` 里声明其在哪个时刻被 `fully_preserved` |
| 只提供**身份 / 服装** | 写进 `<Subject N>` 定义，**不独立成条** |
| 只提供**环境 / 场景** | 写进"环境"这个 `<Subject N>` 定义，retention 给 **`weak_reference`** |
| 只提供**风格** | 写进 style 句 |

## 二、最重要的坑：环境图给成构图锚，镜头会被拉回它的构图

**错误写法**（常见）：
```
<Picture 2> 是主体所处的场景（独立成条）
retention：<Picture 2>：fully_preserved - 外廊的空间结构、柱列、地砖、宫灯霓虹…全程保留
```
后果：**等于亲口把场景图声明成"构图锚"** → 模型持续把镜头拉回那张图的构图。
实测表现：拉镜头**不沿走廊纵深后退，而是落回场景图那个斜角构图**。

**正确写法**：
```
subject_definitions:
<Subject 2> 是主体所处的环境——…；其空间形制、材质与光位氛围参照 <Picture 2>。

retention_analysis:
<Subject 2>（环境，出现于 [Shot 1] 全片）：weak_reference - 只保留外廊这一类空间的形制、材质与光位氛围；
<Picture 2> 仅作环境形制与光位氛围的参照；构图与机位一律以本提示词的镜头描述为准。
```
（末句必须写成**正向**表述，不要写"<Picture 2> 不约束构图"——那是裸否定。）

## 三、环境描写越细，起手景别越宽

- 逐一点名"必须可见"的环境元素（柱列、地砖、宫灯、竹丛…）→ 模型为了把它们全塞进画面，**把画面拉宽**；
- 改成**一句概括**后，**起手景别自动收紧**（实测：同一镜从"全身远景"变成"腰部以上"）；
- 这是**唯一被验证有效的"锁半身"手段**——crop-line 句、腰部以上裁切参考图、构图锚图三种做法全部无效。

**建议的环境句模板**（一句，不定点）：
> `场景是一座中国古典庭院外廊与克制赛博朋克科技相融的白天实景，午后阳光自开敞一侧斜射。`
> （需要露天场景时另写明"站在外廊之外的露天庭院里，头顶是开阔的天空"——**俯视类镜头必须这样做**，否则屋檐会挡死）

## 四、首帧锚定的取舍（实测）

| | 挂首帧图 | 不挂首帧图（文字锁起手） |
|---|---|---|
| 起手跳帧 | **会跳一下**（首帧与动起来之间） | 无（前 5 帧差 0.002–0.09，平滑） |
| 起手复现性 | 高（逐帧一致） | **只能"大致一致"**（同镜跨条件差异明显） |
| 是否压制运镜幅度 | **否**（实测三镜都完整走出运动、幅度甚至更大） | — |
| 真正的差别 | 在**起点**：不挂首帧时模型会自己发明起始构图 | — |

**推荐**：需要稳定起点时用**文字锁起手**；**全身镜不宜作拉远镜头的首帧，可作尾帧**。

## 五、环境修补句会变成构图指令（2026-10-06 F10 案例实测）

**事故**：为堵住「可填充的空洞」写了修补句 `被这根柱身遮住的是廊道向纵深延伸的柱列与地砖`——本意只是交代遮挡物后面是什么，
成片却被改成**沿长廊纵深看**（柱列收灭点、地砖消失线），横移运镜失去横向空间，模型复制了第二个主角补位。

**规范**（与官方 H3LAB-FRAMING-SCENE-01 一致）：
1. **描述主体所处的环境，而不是列出必须可见的环境元素**——环境清单会把画面推宽、把构图推走。
2. **写任何环境句之前自问：这句是不是在指定机位朝向 / 构图方向？**「向纵深延伸」「尽头是」「深处」这类方位词都是构图指令。
3. 横移（TRUCK）镜必须给**横向空间**：写「长长的外廊从左向右横贯整个画面」这类**走向句**；规避「纵深」字眼（前后层次改说「前后错位」）。
4. **画幅是隐藏变量**：同一提示词 + 同一种子，1.8:1 不出双主体，4:3 就出——横向运镜在窄画幅里没有位移空间，
   模型用「复制一个人」补位。跨画幅复用提示词前先预期这个风险（案例详表见 test-design-expert KB B-13）。

**防复制双保险写法**（实测有效）：
- `画面中自始至终只有 <Subject 1> 这一位人物。`
- 强调版：`画面里出现的每一处身体、每一段衣袖与每一缕头发都只属于这一位人物。`
- 配合**具体化遮挡物**（给「可填充的空洞」一个确定的内容），而不是留白让模型自己发明。

## 六、`<Picture N>` 不进 `summary` 与 `detailed_description`（2026-10-08 用户纠正 · 已翻车三次）

**判据的下一层：不只是"别独立成条"，而是"这两段里根本不出现 `<Picture N>` 这个标签"。**

| 段落 | `<Picture N>` 可否出现 | 说明 |
|---|---|---|
| `subject_definitions` | ✅ **必须出现** | 来源声明：`<Subject 1> 是 <Picture 1> 四视图角色卡中的少女…`（内联定义，图片不独立成条） |
| `retention_analysis` | ✅ 可出现 | 只在图真的作首帧 / 末帧 / 关键帧锚时 |
| `summary` | ❌ **禁止** | 剧情与参考关系一律用 `<Subject N>` 讲 |
| `detailed_description` | ❌ **禁止** | 出现即被模型当**锚点帧 / 构图锚**，构图被拉回那张图的取景 |

**成因**：`<Picture N>` 在 H3 规范里的语义就是"一个具体的帧"（首帧 / 关键帧 / 末帧 / 编辑关键帧 / 构图锚，ref-en §2.2）。
把它写进正在描述画面的正文，等于告诉模型"这一帧要长成这张图"——**整段运镜会被这张图的构图拽住**。

**正反例**

- ✗ `<Subject 1>——<Picture 1> 中的少女——立在床边的地板上`
- ✗ `<Picture 1> 中少女的面容与整套汉服在这一刻清晰可见`
- ✗ summary：`人物身份、发型与整套汉服造型均来自 <Picture 1>`
- ✓ `<Subject 1> 立在床边的地板上` ／ `<Subject 1> 的面容与整套汉服在这一刻清晰可见`
- ✓ summary：`目标视频展示 <Subject 1> 在自己的卧室里向上跃起…整段以一条连续长镜一气呵成。`（参考关系交给 `subject_definitions` + `retention_analysis`）

**机械自检（交付前必做）**：抠出 `summary` 与 `detailed_description` 两段，统计 `<Picture` 出现次数 → **应为 0**。
两段之外出现是正常的。
