# Co-op Game Intro Generator（本地版 · 逐步确认式）

> 本文件由原始 skill `co-op-game-intro-generator` 改造为「本地版 · 逐步确认式」。
> **本地化改造总则 v2（纯提示词 · 逐步确认 · 交付物门）**
>
> **⏹ 门控硬规则（真停顿 · 已生效）**：本 skill 中每个 `⏸ 确认门` 与 `⏸ 交付物门` 均为**硬性停止点**，不是建议。固定执行顺序：① 仅输出当前步骤交付物（提示词 / 文本计划 / 分镜脚本等）；② **立即调用 AskUserQuestion 工具**，给三选项「✅ 确认，继续下一步」「✏️ 修改当前步」「⏸ 暂停 / 停止或换方向」；③ **等待用户回复**，本回复内**绝不可预生成任何后续步骤**（即使你觉得能一次写完）。任一 `⏸` 门不得跳过 / 合并，也不得仅用一句"请确认"文字代替——必须用 AskUserQuestion 真正阻塞。
> 1. **生图只给提示词，不调用任何生图工具**：确认图等生图步骤只输出文生图提示词；用户自行用任意工具生成图像，并把**图像文件路径或地址返回给我**。本 skill 不硬编码任何 ComfyUI 工作流路径。
> 2. **每一步都确认 + 交付物门（核心规则）**：每个步骤产出后我都会暂停，等你「确认 / 修改」。生图步骤必须等你**返回图像地址**后，才进入视频提示词步骤（视频提示词以该图作参考图）。
> 3. **视频提示词调用 `h3-prompt-writing` skill**：视频提示词均调用用户级 `h3-prompt-writing` skill（纯文本、无需 API）来写；以你返回的图像为参考图，按其 I2VA / Ref2VA 结构输出完整 H3 视频提示词，并附端口 / 顺序 / 时长 / 分辨率设置建议，由你在本地 H3 节点自行执行。
> 4. **语音 / 音乐先询问（已升级为「音频模式门」）**：进入流程第一步（方向/简报锁定）时，必须先用 AskUserQuestion 问你**音频方案**，二选一：
>    - **A) 统一 H3 音频**：旁白 + 对白 + BGM 全部由 H3 原生音频驱动生成（最省事，音色/配乐与画面同步，无需外部文件）。
>    - **B) 分离生成**：旁白/对白只给提示词（你用任意 TTS 工具，推荐用「参考/音色克隆」模式保证跨镜头一致；不绑定 MOSS-TTS）、BGM 用 ACE-Step 1.5 本地生成（调用 `ace-step-1.5-prompt-writer` skill）、对白分别生成，后期合成。
>    - 记录你的选择，后续「视频提示词步骤」与「音频步骤」依此分支执行。
> 5. **旁白/对白一致性（分离模式必做）**：若选 B 且含旁白/对白，提醒你把【音色参考文件】（.wav/.mp3，代表目标音色）放到**当前项目文件夹（你运行本 skill 的工作目录）**，并在调用 TTS 时使用「参考模式 / 音色克隆」，确保多镜头音色统一；若你未提供该文件，先暂停请其提供，禁止无参考直接生成（否则各镜头音色漂移）。
> 6. **BGM 分离 -> 视频提示词只规划视觉（重要）**：若选 B，BGM 由 ACE-Step 1.5 单独生成，因此**调用 `h3-prompt-writing` 写视频提示词时不可规划 BGM/旁白/对白的音频出现**（如"音乐渐强""旁白响起""对话切入"等），只规划镜头/动作/画面；音频在后期合成。若选 A，视频提示词可正常包含音频驱动指令，无需单独生成音频。
> 7. **删除自动剪辑 / 拼接**：改为提供"剪辑思路"。
> 8. **规划 / 分镜 / 排版等文本方法论沿用原 skill**。
> 9. **删除"表情图"相关提示词**。

## 必需参考模板（沿用）
- `references/h3-confirmation-image-template.md`：STEP3 写确认图 prompt 时按字段填（framework/palette/UI/character/typography/layout/负向）。
- `references/h3-video-prompt-template.md`：STEP6 填最终 H3 视频提示词（由 `h3-prompt-writing` skill 主导生成）。
> 若模板缺失，停报 skill 包不完整，不要即兴改结构。

## STEP 1：问视觉风格
同原 skill：预设风格或自定义；风格优先级最高，控制补充风格语、色板、背景纹理、角色渲染、表情、服装、UI 色、按钮/图标、字体质感。
- ⏸ **确认门**：风格呈现后暂停，等你确认。

## STEP 2：收玩家与游戏信息
同原 skill：PLAYER1/PLAYER2 名、游戏名；若有角色图仅用于身份映射（脸廓/发型/眼镜/比例/特征），重绘为所选风格、保留身份锚。

## STEP 3：写 GPT 确认图 prompt（只给提示词）
同原 skill：加载 `h3-confirmation-image-template.md`，按 14 项字段填（总风格/色板/构图/背景/角色风格/A/B 角色/光照/游戏UI/布局/按钮/玩家卡/图标/字体）。
**调用用户级 `image-prompt-writer-local` skill** 生成富结构提示词：传入 场景类型=人像/海报（确认图=角色+菜单框架）、风格上下文=选定游戏美术风格、主体与要求=14 项字段（总风格/色板/构图/背景/角色风格/A/B 角色/光照/UI/布局/按钮/玩家卡/图标/字体）。它返回「通用风格锚 + 确认图四段式详描」，你原样呈现。
**本步骤产出**：确认图的**文生图提示词**（来自上一步 skill 输出）。
- ⏸ **交付物门（必过）**：提示词给你后暂停。请你用任意工具生成确认图并**返回图像地址**。收到后才进入 STEP 4/5/6。

## STEP 4：等批准（确认图）
同原 skill：你批准前不生视频；若改风格/名/游戏/身份/方向，回到 STEP3。
- ⏸ **确认门**：收到你的确认图后，等你批准/修改。

## STEP 5：填视频 prompt 准备
加载 `h3-video-prompt-template.md` 所需字段（确认风格/角色参考/玩家名/游戏名/UI 文案/事件时序/运动方向/负向），整理为输入材料。

## STEP 6：视频提示词（调用 h3-prompt-writing + 设置建议 + 交付物门）
**不再由本 skill 直接写 H3 提示词，改为调用 `h3-prompt-writing` skill**：
- 输入：STEP3 返回并 STEP4 批准的确认图图像地址（角色+菜单框架）+ STEP5 字段材料。
- **调用用户级 `h3-prompt-writing` skill**（纯文本、无需 API），按其 I2VA / Ref2VA 结构输出完整 H3 视频生成提示词；并附设置建议：
  - 参考图1 = 确认的确认图（角色+菜单框架）→ 接入 H3 节点「图像参考 / image reference」端口（若区分角色/场景，确认图整图作主参考）
  - 参考图2 = 如有单独场景/角色参考图，依次接入对应端口；本 skill 通常单张确认图即可
  - 音频（依总则「音频模式门」分支）：模式=统一H3 时，H3 原生音频或自备菜单音效接「音频输入」端口；模式=分离 时，本视频提示词**仅规划视觉**，音频后期合成。
  - 时长 = 由你定（开场动画通常 15–30s）；分辨率 = 16:9（1920×1080）；其余你自定
  - 模型标注 MiniMax-H3；本地用 Wan/Animate2 亦可
- **本步骤产出**：完整 H3 视频提示词 + 端口/顺序/时长/分辨率设置建议。
- ⏸ **交付物门（可选）**：你确认提示词后自行在 H3 执行，返回成片地址（可选）。

## STEP 7：修复常见失败
同原 skill（文字不清→减字；身份互换→加强名/位/色；脸漂移→复用上传参考+保留身份锚；风格弱→重写风格相关字段而非改框架）。
